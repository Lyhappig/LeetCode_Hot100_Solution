## 无重复字符的最长子串

### 问题

给定一个字符串 `s` ，请你找出其中不含有重复字符的**最长子串**的长度。

提示：

- $0 \leq$ `s.length` $\leq 5\times 10^4$
- `s` 由英文字母、数字、符号和空格组成

### 思路一（双指针）

以字符串 $abcabcbb$ 为例，找出从每一个字符开始的，不包含重复字符的最长子串，那么其中最长的那个字符串即为答案。枚举的结果如下，其中括号中表示选中的字符以及最长的字符串：

- 以 $(a)bcabcbb$ 开始的最长字符串为 $(abc)abcbb$
- 以 $a(b)cabcbb$ 开始的最长字符串为 $a(bca)bcbb$
- 以 $ab(c)abcbb$ 开始的最长字符串为 $ab(cab)cbb$
- 以 $abc(a)bcbb$ 开始的最长字符串为 $abc(abc)bb$
- 以 $abca(b)cbb$ 开始的最长字符串为 $abca(bc)bb$
- 以 $abcab(c)bb$ 开始的最长字符串为 $abcab(cb)b$
- 以 $abcabc(b)b$ 开始的最长字符串为 $abcabc(b)b$
- 以 $abcabcb(b)$ 开始的最长字符串为 $abcabcb(b)$

**写法一：最长子串的区间为 $[l, r)$**

设函数 $f(l)$ 代表以 $l$ 为起点的不包含重复字符的最长子串的**右(开)边界**。当自变量 $l \rightarrow l + 1$，$f(l) \leq f(l + 1)$，满足双指针的**单调性**。

通俗的说，当选择字符串中的第 $l$ 个字符作为起始位置，并且得到了不包含重复字符的最长子串的结束位置为 $r$ 。那么当我们选择第 $l+1$ 个字符作为起始位置时，首先从 $l+1$ 到 $r$ 的字符显然是不重复的，并且由于少了原本的第 $l$ 个字符，我们可以尝试继续增大 $r$，直到右侧出现了重复字符为止。 

为每个字符设置一个计数器，指针 $l,r$ 初始均指向数组的第一个元素，算法流程为：

- $r$ 指向的字符计数器加一，$r$ 右移一位。重复上述过程直到统计到了重复字符，此时区间 $[l, r)$ 即为以 $l$ 为起点的不包含重复字符的最长子串

- $l$ 指向的字符计数器减一，$l$ 向右移动一位
- $r$ 越界后并不影响答案，$l$ 遍历完整个字符串为结束条件

**写法二：最长子串的区间为 $[l, r]$**

设函数 $f(r)$ 代表以 $r$ 为终点的不包含重复字符的最长子串的**左(闭)边界**。当自变量 $r \rightarrow r + 1$，$f(r) \leq f(r + 1)$，满足双指针的**单调性**。

为每个字符设置一个计数器，指针 $l,r$ 初始均指向数组的第一个元素，算法流程为：

- 将 $r$ 指向的字符加入已经遍历过的子串 $[l, r)$，$r$ 指向的字符计数器加一，此时子串区间为 $[l, r]$
- 若 $r$ 指向的字符已经被统计两次，$l$ 指向的字符计数器减一，$l$ 向右移动一位，重复此过程直到可以得到一个无重复子串 $[l, r]$
- 此时区间 $[l, r]$ 即为以 $r$ 为终点的不包含重复字符的最长子串，更新答案，$r$ 右移一位
- 两个指针移动过程中始终满足 $l \leq r$，因此以 $r$ 遍历完字符串为结束条件

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
    int lengthOfLongestSubstring(string s) {
        int ans = 0;
        unordered_map<char, int> cnt;
        for (int l = 0, r = 0; l <= r; l++) {
            while (r < s.size() && !cnt[s[r]]) {
                ++cnt[s[r++]];
            }
            ans = max(ans, r - l);
            --cnt[s[l]];
        }
        return ans;
    }
    
    int lengthOfLongestSubstring(string s) {
        int ans = 0;
        unordered_map<char, int> cnt;
        for (int l = 0, r = 0; r < s.size(); r++) {
            ++cnt[s[r]];
            while (cnt[s[r]] > 1) {
                --cnt[s[l++]];
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
}
```

### 思路二（动态规划）

设 $f[i]$ 代表以 $i$ 结尾的无重复字符最长子串的长度：

- 若 $s[i]$ 在前缀中还未出现，那么 $f[i] = f[i - 1] + 1$
- 否则找到 $s[i]$ 在位置 $i$ 之前出现的最近位置 $p$，前一个状态构成的无重复字符子串的最左边界为 $l = i - f[i - 1]$
  - 若 $p < l$，则该字符可以跟在上一个状态后面构成一个更长的无重复字符子串
  - 否则上一个状态的子串需要从位置 $p$ 分成 $[l, p]$ 和 $(p, i - 1]$ 两部分，当前状态的无重复字符子串构成的区间为 $(p, i]$

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        if (s == "") return 0;
        unordered_map<char, int> pos;
        vector<int> f(s.size(), 0);
        f[0] = 1;
        pos[s[0]] = 0;
        int ans = 1;
        for (int i = 1; i < s.size(); i++) {
            if (!pos.count(s[i])) {
                f[i] = f[i - 1] + 1;
            } else {
                int x = i - f[i - 1];
                if (pos[s[i]] < x) {
                    f[i] = f[i - 1] + 1;
                } else {
                    f[i] = i - pos[s[i]];
                }
            }
            pos[s[i]] = i;
            ans = max(ans, f[i]);
        }
        return ans;
    }
};
```

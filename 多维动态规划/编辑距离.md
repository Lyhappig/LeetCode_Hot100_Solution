## 编辑距离

### 问题

给你两个单词 `word1` 和 `word2`， *请返回将 `word1` 转换成 `word2` 所使用的最少操作数* 。

你可以对一个单词进行如下三种操作：

- 插入一个字符
- 删除一个字符
- 替换一个字符

提示：

- `0 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 由小写英文字母组成

### 思路（DP）

如果我们有单词 A 和单词 B：

- 对单词 A 删除一个字符和对单词 B 插入一个字符是等价的。例如当单词 A 为 doge，单词 B 为 dog 时，我们既可以删除单词 A 的最后一个字符 e，得到相同的 dog，也可以在单词 B 末尾添加一个字符 e，得到相同的 doge；
- 同理，对单词 B 删除一个字符和对单词 A 插入一个字符也是等价的；

这样以来，本质不同的操作实际上只有：

1. 在单词 A 中插入一个字符；
2. 在单词 B 中插入一个字符；
3. 修改单词 A 或单词 B 的一个字符。

设 $f[i,j]$ 表示字符串 A 的前 $i$ 个字符和字符串 B 的前 $j$ 个字符之间的编辑距离：

- 若 $A[i] = B[j]$，那么 $f[i,j]=f[i-1,j-1]$，代表相对于状态 $f[i-1,j-1]$ 不需要任何修改操作；
- 否则两个位置的字符不匹配：
  - 要么删除 $A[i]$，这等价于状态 $f[i-1,j]+1$；
  - 要么删除 $B[j]$，这等价于状态 $f[i,j-1]+1$；
  - 要么修改 $A[i]$ 或者 $B[j]$ 其中一个，使得二者相等，这等价于 $f[i-1,j-1]+1$。

注意 $\forall i,f[i,0]=i$，并且 $\forall j,f[0,j]=j$。

#### 时空复杂度

时间复杂度 $O(n^2)$

空间复杂度 $O(n^2)$​

#### 代码

```C++
class Solution {
public:
    int minDistance(string word1, string word2) {
        int n = word1.size();
		int m = word2.size();
        const int inf = 0x3f3f3f3f;
		vector<vector<int>> f(n + 1, vector<int>(m + 1, inf));
        f[0][0] = 0;
        for (int i = 1; i <= n; i++) f[i][0] = i;
        for (int j = 1; j <= m; j++) f[0][j] = j;
		for (int i = 1; i <= n; i++) {
			for (int j = 1; j <= m; j++) {
				if (word1[i - 1] == word2[j - 1]) {
					f[i][j] = f[i - 1][j - 1];
				} else {
					// 删除s1[i]
					f[i][j] = min(f[i][j], f[i - 1][j] + 1);
					// 删除s2[j]
					f[i][j] = min(f[i][j], f[i][j - 1] + 1);
					// 替换其中一个，使得匹配
					f[i][j] = min(f[i][j], f[i - 1][j - 1] + 1);
				}
			}
		}
		return f[n][m];
    }
};
```

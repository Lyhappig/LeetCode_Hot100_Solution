## 不同路径

### 问题

一个机器人位于一个 `m x n` 网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

![img](assets/1697422740-adxmsI-image.png)

提示：

- `1 <= m, n <= 100`
- 题目数据保证答案小于等于 $2\times 10^9$

### 思路一（DP）

设 $f[i,j]$ 表示处于位置 $(i,j)$ 时的路径方案数：

- 若从 $(i-1,j)$ 到达 $(i,j)$，则 $f[i,j]=f[i,j] + f[i-1,j]$；
- 若从 $(i,j-1)$ 到达 $(i,j)$，则 $f[i,j]=f[i,j] + f[i,j-1]$。

最终答案即为 $f[m-1,n-1]$。

#### 时空复杂度

时间复杂度 $O(n\times m)$

空间复杂度 $O(n\times m)$

#### 代码

```C++
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> f(m, vector<int>(n, 0));
        f[0][0] = 1;
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (i - 1 >= 0) {
                    f[i][j] += f[i - 1][j];
                }
                if (j - 1 >= 0) {
                    f[i][j] += f[i][j - 1];
                }
            }
        }
        return f[m - 1][n - 1];
    }
};    
```

### 思路二（组合数学）

无论哪种走法，都需要向下走 $n-1$ 步，向右走 $m-1$ 步，因此答案为：
$$
\binom{n+m-2}{m-1}=\binom{n+m-2}{n-1}=\frac{(n+m-2)!}{(m-1)!\cdot (n-1)!}
$$

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    int calc(int n, int k) {
        k = min(k, n - k);
        long long ans = 1;
        for (int i = 1; i <= k; i++) {
            ans = ans * (n + 1 - i) / i;
        }
        return ans;
    }

    int uniquePaths(int m, int n) {
        return calc(n + m - 2, m - 1);
    }
};
```

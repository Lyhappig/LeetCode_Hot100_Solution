## 括号生成

### 问题

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

提示：

- `1 <= n <= 8`

### 思路一（枚举）

设 0/1 分别代表左括号和右括号，通过二进制状态压缩，枚举生成所有 $2^n$ 个括号字符串。枚举所有括号字符串，使用栈 $O(n)$ 判断一个括号组合是否合法。

#### 时空复杂度

时间复杂度 $O(n\times 2^{2n})$

空间复杂度 $O(2^{2n})$​

#### 代码

```C++
class Solution {
public:
    bool checkValidString(const string& s) {
        stack<char> stk;
        for (char c : s) {
            if (c == '(') {
                stk.push('(');
            } else {
                if (stk.empty()) {
                    return false;
                }
                stk.pop();
            }
        }
        return stk.empty();
    }

    vector<string> generateParenthesis(int n) {
        string str(2 * n, '(');
        vector<string> ans;
        for (int s = 0; s < (1 << (2 * n)); s++) {
            for (int j = 0; j < 2 * n; j++) {
                if ((s & (1 << j)) != 0) {
                    str[j] = ')';
                } else {
                    str[j] = '(';
                }
            }
            if (checkValidString(str)) {
                ans.push_back(str);
            }
        }
        return ans;
    }
};
```

### 思路二（搜索）

在构造一个合法的括号序列时，满足如下两个条件：

1. 括号序列一定以左括号开头
2. 任何时候都满足左括号数量大于等于右括号数量

设 $d(cur,n,l,r)$ 分别代表当前构造的括号序列、最终左右括号的最大数量、目前左括号数量、目前右括号数量，并且搜索时：

1. 若左括号数量小于 $n$，添加左括号并搜索下一层，回溯时撤销左括号
1. 若右括号数量小于左括号数量，添加右括号并搜索下一层，回溯时撤销右括号

#### 时空复杂度

时间复杂度 $O(\frac{4^n}{\sqrt{n}})$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    vector<string> generateParenthesis(int n) {
        vector<string> ans;
        function<void(string&, int, int, int)> dfs = [&](string &cur, int n, int l, int r){
            if (cur.size() == n * 2) {
                ans.push_back(cur);
                return;
            }
            if (l < n) {
                cur.push_back('(');
                dfs(cur, n, l + 1, r);
                cur.pop_back();
            }
            if (r < l) {
                cur.push_back(')');
                dfs(cur, n, l, r + 1);
                cur.pop_back();
            }
        };
        string seq;
        dfs(seq, n, 0, 0);
        return ans;
    }
};
```

### 思路三（动态规划）

设 $f[k]$ 表示 $k$ 对括号的所有方案，初始令 `f[0] = ""`。若已知 $f[i-1]$ 求 $f[i]$，对于字符串 $s$，考虑新加入的一对括号放在哪里：

1. 单独添加在字符串的首尾，即 `()s` 和 `s()`。 
2. 将整个 $s$ 括起来，即 `(s)`。
3. 将字符串分为两个合法的括号子字符串 $p,q$，可以将整个 $p$ 或 $q$ 括起来，即 `(p)q` 或 `p(q)`。

注意到第三种情况无需考虑 `p()q` 和 `pq()` 等情况，因为划分两部分时包含了这些情况。可以将上述三种情况做个统一：**将 $s$ 分为两部分 $p,q$（可以为空），将整个 $p$ 括起来并和 $q$ 拼接**，恰好不重不漏的得到所有的方案，用状态转移方程表示为：
$$
f[i]=\sum_{j=0}^{i-1}\{\text{`}(\text{'}+\sum f[j]+\text{`}(\text{'}+\sum f[i-j-1]\}
$$
最终 $f[n]$ 中保存了答案。

#### 时空复杂度

时间复杂度 $O(\frac{4^n}{\sqrt{n}})$

空间复杂度 $O(\frac{4^n}{\sqrt{n}})$

#### 代码

```C++
class Solution {
public:
    vector<string> generateParenthesis(int n) {
        vector<vector<string>> f(n + 1);
        f[0].push_back("");
        for (int i = 1; i <= n; i++) {
            for (int j = 0, k; j < i; j++) {
                k = i - j - 1;
                for (auto &s1 : f[j]) {
                    for (auto &s2 : f[k]) {
                        f[i].push_back("(" + s1 + ")" + s2);
                    }
                }
            }
        }
        return f[n];
    }
};
```

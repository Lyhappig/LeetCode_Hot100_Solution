## 组合总和

### 问题

给你一个 **无重复元素** 的整数数组 `candidates` 和一个目标整数 `target` ，找出 `candidates` 中可以使数字和为目标数 `target` 的 所有 **不同组合** ，并以列表形式返回。你可以按 **任意顺序** 返回这些组合。

`candidates` 中的 **同一个** 数字可以 **无限制重复被选取** 。如果至少一个数字的被选数量不同，则两种组合是不同的。 

对于给定的输入，保证和为 `target` 的不同组合数少于 `150` 个。

提示：

- `1 <= candidates.length <= 30`
- `2 <= candidates[i] <= 40`
- `candidates` 的所有元素 **互不相同**
- `1 <= target <= 40`

### 思路（搜索）

设 $d(i,sum)$ 表示当前搜索到第 $i$ 个数，选出的和为 $sum$ 的状态。对于第 $i$ 个数，要么不选，继续搜索 $d(i+1,sum)$；要么从中选出 $[1,k],k\times a[i] \leq target$ 个，将选出的数以及个数放入栈中，回溯时弹出栈顶撤销状态。

#### 时空复杂度

时间复杂度 $O(n\times 2^n)$

空间复杂度 $O(target)$​

#### 代码

```C++
class Solution {
public:
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        vector<vector<int>> ans;
        vector<pair<int, int>> chosen;
        function<void(int, int)> dfs = [&](int i, int curSum) {
            if (curSum == target) {
                vector<int> res;
                for (const auto &pr : chosen) {
                    for (int j = 0; j < pr.first; j++) {
                        res.push_back(pr.second);
                    }
                }
                ans.push_back(res);
                return;
            }
            if (curSum > target || i >= candidates.size()) return;
            dfs(i + 1, curSum);
            for (int k = 1; curSum + k * candidates[i] <= target; k++) {
                chosen.push_back({k, candidates[i]});
                dfs(i + 1, curSum + k * candidates[i]);
                chosen.pop_back();
            }
        };
        dfs(0, 0);
        return ans;
    }
};
```

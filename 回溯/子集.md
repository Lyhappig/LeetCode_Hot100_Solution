## 子集

### 问题

给你一个整数数组 `nums` ，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。

解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

提示：

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有元素 **互不相同**

### 思路一（搜索）

使用栈保存子集中的元素，按照每个元素选或不选的思路递归求解，回溯时通过弹出栈顶恢复状态。

#### 时空复杂度

时间复杂度 $O(2^n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        int n = nums.size();
        vector<vector<int>> ans;
        vector<int> res;
        function<void(int)> dfs = [&](int d) {
            if (d >= n) {
                ans.push_back(res);
                return;
            }
            dfs(d + 1);
            res.push_back(nums[d]);
            dfs(d + 1);
            res.pop_back();
        };
        dfs(0);
        return ans;
    }
};
```

### 思路二（二进制枚举）

通过状态压缩的思想，每个元素选/不选将其视为 1/0，$n$ 个元素组成的二进制数即表示选取的集合，集合共有 $2^n$，因此枚举 $[0,2^n)$ 即可得到所有的二进制集合。

#### 时空复杂度

时间复杂度 $O(2^n)$

空间复杂度 $O(n)$

#### 代码

```C++
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> ans;
        vector<int> res;
        int n = nums.size();
        for (int mask = 0; mask < (1 << n); ++mask) {
            res.clear();
            for (int i = 0; i < n; ++i) {
                if (mask & (1 << i)) {
                    res.push_back(nums[i]);
                }
            }
            ans.push_back(res);
        }
        return ans;
    }
};
```

## 全排列

### 问题

给定一个不含重复数字的数组 `nums` ，返回其 *所有可能的全排列* 。你可以 **按任意顺序** 返回答案。

提示：

- `1 <= nums.length <= 6`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有整数 **互不相同**

### 思路一（递归）

问题抽象为：有 $n$ 个空位，从左到右依次填入 $n$ 个数，每个数只能使用一次。在枚举每个位置时尝试枚举 $n$ 个数，没有使用过的数填入该位置，标记后递归下个位置，在回溯时清除标记。

不使用标记做法的思路为：将题目给定的 $n$ 个数划分为左右两个部分，左边表示已经填过的数，右边表示待填的数，在回溯的时候动态维护这个数组。具体来说：假设正在填第 $i$ 个位置，那么数组中 $[0,i-1]$ 是已经填过数的集合，$[i,n-1]$ 是待填入数的集合。只需尝试用下标 $[i,n-1]$ 中的数去填第 $i$ 个数，假设选取了下标为 $j$ 的数，那么只需要交换 $i,j$ 两个数，回溯后交换回来完成撤销操作。

#### 时空复杂度

时间复杂度 $O(n\times n!)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    void dfs(vector<vector<int>>& ans, vector<int>& res, int depth, int n){
        if (depth == n) {
            ans.emplace_back(res);
            return;
        }
        for (int i = depth; i < n; i++) {
            swap(res[i], res[depth]);
            dfs(ans, res, depth + 1, n);
            swap(res[i], res[depth]);
        }
    }

    vector<vector<int>> permute(vector<int>& nums) {
        vector<vector<int>> ans;
        dfs(ans, nums, 0, nums.size());
        return ans;
    }
};
```

### 思路二（下一个排列）

对于初始数组执行 $n!$ 次下一个排列操作即可，下一个排列操作可以采用 $O(n)$ 的算法解决。

#### 时空复杂度

时间复杂度 $O(n!)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        int n = nums.size();
        int i = n - 1;
        while (i >= 1 && nums[i - 1] >= nums[i]) {
            i--;
        }
        if (i == 0) {
            reverse(nums.begin(), nums.end());
        } else {
            int j = n - 1;
            while (j > i && nums[j] <= nums[i - 1]) {
                j--;
            }
            swap(nums[i - 1], nums[j]);
            reverse(nums.begin() + i, nums.end());
        }
    }

    vector<vector<int>> permute(vector<int> &nums) {
        vector<vector<int>> ans;
        int tot = 1;
        for(int i = 1; i <= nums.size(); i++) tot *= i;
        sort(nums.begin(), nums.end());
        while (tot--) {
            ans.push_back(nums);
            nextPermutation(nums);
        }
        return ans;
    }
};
```

## 单词搜索

### 问题

给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

提示：

- `m == board.length`
- `n = board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 仅由大小写英文字母组成

### 思路（搜索）

设 $d(r,c,k)$ 表示网格中处于位置 $(r,c)$ 的字符和模式字符串 $word$ 的第 $k$ 个字符的匹配情况，搜索过程如下：

- 若 $k\geq|word|$ 则匹配成功，结束搜索。
- 标记位置 $(r,c)$ 的字符 $x$ 已被访问，当且仅当 $x=word[k]$，从当前位置的四个方向进行下一层搜索；
- 回溯后撤回位置 $(r,c)$ 的字符 $x$ 的标记，返回上一层。

#### 时空复杂度

时间复杂度 $O(n\cdot m\cdot 3^L)$

空间复杂度 $O(n\cdot m)$​

#### 代码

```C++
class Solution {
public:
    bool exist(vector<vector<char>>& board, string word) {
        int n = board.size(), m = board[0].size();
        int len = word.size();
        const int dx[] = {0, 0, 1, -1};
        const int dy[] = {1, -1, 0, 0};

        vector<vector<bool>> vis(n, vector<bool>(m));
        bool findWord = false;
        function<void(int, int, int)> dfs = [&](int r, int c, int k) {
            if (findWord) return;
            if (k >= len) {
                findWord = true;
                return;
            }
            if (r < 0 || r >= n || c < 0 || c >= m) return;
            if (vis[r][c] || board[r][c] != word[k]) return;
            vis[r][c] = true;
            for (int i = 0, x, y; i < 4; i++) {
                x = r + dx[i], y = c + dy[i];
                dfs(x, y, k + 1);
            }
            vis[r][c] = false;
        };

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (board[i][j] == word[0]) {
                    dfs(i, j, 0);
                    if (findWord) return true;
                }
            }
        }
        return false;
    }
};
```

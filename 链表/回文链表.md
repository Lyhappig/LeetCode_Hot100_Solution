## 回文链表

### 问题

给你一个单链表的头节点 `head` ，请你判断该链表是否为回文链表。如果是，返回 `true` ；否则，返回 `false` 。

提示：

- 链表中节点数目在范围 $[1,10^5]$ 内
- `0 <= Node.val <= 9`

### 思路一（递归）

对于简单字符串的回文判断，设置首尾两个指针相向移动即可。链表的头指针直接给出，但是尾指针没有给出且不具备从后向前逐一移动的能力。可以**使用递归来模拟从后向前移动的过程**，头指针只需要再设置一个全局变量。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
private:
    ListNode *front;

    int dfs(ListNode *back) {
        if (!back) return 1;
        int ret = dfs(back->next);
        ret = ret & (front->val == back->val);
        front = front->next;
        return ret;
    }
public:
    bool isPalindrome(ListNode* head) {
        this->front = head;
        return dfs(head);
    }
};
```

### 思路二（迭代）

整个流程可以分为以下五个步骤：

1. 找到前半部分链表的尾节点；
2. 反转后半部分链表；
3. 判断是否回文；
4. 恢复链表；
5. 返回结果。

其中第一步可以通过快慢指针的方式找到。前半部分链表的尾节点的下一个节点，就是后半部分的头节点，反转后半部分的链表。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

### 代码

```c++
class Solution {
private:
    ListNode* reverseList(ListNode* head) {
        if (head == nullptr) return head;
        ListNode* preNode = nullptr;
        ListNode* tempHead = head->next;
        while (tempHead != nullptr) {
            head->next = preNode;
            preNode = head;
            head = tempHead;
            tempHead = tempHead->next;
        }
        head->next = preNode;
        return head;
    }

    ListNode *endOfFirstHalf(ListNode* head) {
        ListNode *slow = head;
        ListNode *fast = head;
        while (fast->next != nullptr && fast->next->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }
        return slow;
    }
public:
    bool isPalindrome(ListNode* head) {
        if (!head) return true;
        ListNode *leftEnd = endOfFirstHalf(head);
        ListNode *newHead = reverseList(leftEnd->next);
        ListNode *left = head;
        ListNode *right = newHead;
        bool ret = true;
        while (left != nullptr && right != nullptr) {
            if (left->val != right->val) {
                ret = false;
                break;
            }
            left = left->next;
            right = right->next;
        }
        leftEnd->next = reverseList(newHead);
        return ret;
    }
};
```

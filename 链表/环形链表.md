## 环形链表

### 问题

给你一个链表的头节点 `head` ，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。**注意：`pos` 不作为参数进行传递** 。仅仅是为了标识链表的实际情况。

*如果链表中存在环* ，则返回 `true` 。 否则，返回 `false` 。

**注意：**

![img](https://assets.leetcode-cn.com/aliyun-lc-upload/uploads/2018/12/07/circularlinkedlist.png)

提示：

- 链表中节点的数目范围是 $[0, 10^4]$
- $-10^5 \leq $ `Node.val` $\leq 10^5$
- `pos` 为 `-1` 或者链表中的一个 **有效索引** 。

### 思路一（哈希表）

使用哈希表记录节点是否已经访问：

- 若当前节点为空，则返回真
- 否则一定会循环到已经出现的节点，返回假

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    bool hasCycle(ListNode *head) {
        unordered_map<ListNode*, bool> mp;
        while (head != nullptr) {
            if (mp.count(head)) {
                return true;
            }
            mp[head] = true;
            head = head->next;
        }
        return false;
    }
};
```

### 思路二（双指针）

龟兔赛跑算法又称 Floyd 判环法，其核心思想就是双指针。设置两个指针初始均指向链表的头部，每次移动时，快指针向前走 $2$ 步，慢指针向前走 $1$​ 步。重复移动过程，当两个指针**第一次相会**时，代表链表存在环。

采用 `while` 循环一开始处在起点不能判断指针相会，因此将 **判断时机放在两个指针移动后**，这样也能保证不重不漏。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$

#### 代码

```C++
class Solution {
public:
    bool hasCycle(ListNode *head) {
        if (!head) return false;
        ListNode *l = head, *r = head;
        while (r->next != nullptr && r->next->next != nullptr) {
            l = l->next;
            r = r->next->next;
            if (l == r) {
                return true;
            }
        }
        return false;
    }
};
```

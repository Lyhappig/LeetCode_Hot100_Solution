## 合并两个有序链表

### 问题

将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。 

**注意：**

![img](https://assets.leetcode.com/uploads/2020/10/03/merge_ex1.jpg)

提示：

- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- 两个链表均按 **非递减顺序** 排列

### 思路一（递归）

假设当前已经排好序的部分为链表 1 头节点到 $h_1$、链表 2 头节点到 $h_2$

- 若 $h_1 < h_2$，则已经排好序部分的下一个节点一定是 $h_1$，此时将问题分解为 $h_1 \rightarrow next$ 和 $h_2$ 排序的子问题，并将排完序的头节点作为 $h_1$ 的后继；
- 否则已经排好序部分的下一个节点一定是 $h_2$，此时将问题分解为 $h_1$ 和 $h_2 \rightarrow next$ 排序的子问题，并将排完序的头节点作为 $h_2$​ 的后继；

递归的中止条件为某个节点为空节点，此时只需要将另一个节点作为排好序部分的后继。**递归的返回值就是子问题排序后的头节点**。

递归处理的过程相当于**从后到前构造排序后的链表，构造的正确性依赖于递归栈，保存了每个子问题的上一个状态和子问题求解后的返回值**。

#### 时空复杂度

时间复杂度 $O(n + m)$

空间复杂度 $O(n + m)$​

#### 代码

```C++
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        if (!list1) return list2;
        if (!list2) return list1;
        if (list1->val < list2->val) {
            list1->next = mergeTwoLists(list1->next, list2);
            return list1;
        } else {
            list2->next = mergeTwoLists(list1, list2->next);
            return list2;
        }
    }
};
```

### 思路二（迭代）

设置两个指针分别指向两个链表的头节点，设置排完序的头节点 `newHead` 和一个 **尾指针** `cur` 指向 `newHead`，尾指针含义是永远指向排完序链表的尾节点。

- 第一阶段的过程类似"交替移动"两个指针：每次只需将值较小的指针作为尾指针的后继，并将该指针和尾指针向后移动一步。当某个指针为空时结束；
- 第二阶段为合并剩余部分：将非空指针作为哨兵节点的后继；

因为设置了排完序的头节点，所以 `newHead->next` 即为答案。

迭代处理的过程相当于**从前到后构造排序后的链表**。

#### 时空复杂度

时间复杂度 $O(n + m)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode *l = list1, *r = list2;
        ListNode *newHead = new ListNode();
        ListNode *cur = newHead;
        while (l != nullptr && r != nullptr) {
            if (l->val <= r->val) {
                cur->next = l;
                l = l->next;
            } else {
                cur->next = r;
                r = r->next;
            }
            cur = cur->next;
        }
        if (l != nullptr) {
            cur->next = l;
        }
        if (r != nullptr) {
            cur->next = r;
        }
        return newHead->next;
    }
};
```

## 反转链表

### 问题

给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表。

![img](https://assets.leetcode.com/uploads/2021/02/19/rev1ex1.jpg)

提示：

- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

### 思路一（递归）

将反转链表的过程考虑为**从尾节点开始不断连接到前一个节点**，链表要找到最后一个节点只能 $O(n)$ 遍历，而反转的过程符合递归回溯的过程，因此递归的思路为：

- 递归到尾节点，直接返回尾节点；
- 回溯时将下一个节点指向当前节点

为了不再对头节点的连接指针置为空，可以在回溯后多一步将当前节点的连接指针置为空的操作。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$

#### 代码

```C++
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (!head || head->next == nullptr) return head;
        ListNode *tail = reverseList(head->next);
        head->next->next = head;
        head->next = nullptr;
        return tail;
    }
};
```

### 思路二（迭代）

将反转链表的过程考虑为**从头节点开始不断连接到前一个节点**，头节点的前一个节点视为空节点，又因为从前到后反转的操作会导致丢失原链表的下一个节点，因此要使用临时变量记录**待反转部分的首个节点**。更一般的想，迭代的做法是**维护了三个相邻且不断向后移动的指针，每次反转一对节点的连接**。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$

#### 代码

```C++
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (head == nullptr) return head;
        ListNode* preNode = nullptr;
        ListNode* tempHead = head->next;
        while (tempHead != nullptr) {
            head->next = preNode;
            preNode = head;
            head = tempHead;
            tempHead = tempHead->next;
        }
        head->next = preNode;
        return head;
    }
};
```

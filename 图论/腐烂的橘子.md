## 腐烂的橘子

### 问题

在给定的 `m x n` 网格 `grid` 中，每个单元格可以有以下三个值之一：

- 值 `0` 代表空单元格；
- 值 `1` 代表新鲜橘子；
- 值 `2` 代表腐烂的橘子。

每分钟，腐烂的橘子 **周围 4 个方向上相邻** 的新鲜橘子都会腐烂。

返回 *直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 `-1`* 。

提示：

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 10`
- `grid[i][j]` 仅为 `0`、`1` 或 `2`

### 思路（bfs）

假设存在一个虚拟的超级源点，它与图中所有腐烂橘子都存在边，在第 `0` 分钟所有腐烂的橘子被超级源点感染，然后继续向四个方向扩展感染。为了减少时间复杂度，**规定每个橘子只被感染一次**，也就是它会被距离最近的腐烂橘子感染。在所有包含腐烂橘子的连通块构成的图中，橘子扩展感染的过程类似于二叉树逐层遍历的过程，使用队列保存二元组：`{腐烂橘子的下标, 被感染时间}`，遍历队列节点时保证时间戳相同的某层腐烂橘子依次出队。当队列为空时结束遍历。

类似《**岛屿数量**》，若某个橘子连通块中没有腐烂的橘子，那么无论经过多久单元格中始终存在新鲜橘子。使用变量记录新鲜橘子被感染的数量，若无法保证所有新鲜橘子都被感染，则输出 `-1`。

#### 时空复杂度

时间复杂度 $O(n \times m)$

空间复杂度 $O(n \times m)$

#### 代码

```C++
const int dir_x[4] = {0, 1, 0, -1};
const int dir_y[4] = {1, 0, -1, 0};

class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        int n = (int)grid.size(), m = (int)grid[0].size();
        queue<pair<int, int>> q;
        vector<vector<int>> dis(n, vector<int>(m, -1));
        int cnt = 0, ans = 0;
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                if (grid[i][j] == 2) {
                    q.push(make_pair(i, j));
                    dis[i][j] = 0;
                } else if (grid[i][j] == 1)
                    cnt += 1;
            }
        }
        while (!q.empty()) {
            pair<int, int> x = q.front();
            q.pop();
            for (int i = 0; i < 4; ++i) {
                int tx = x.first + dir_x[i];
                int ty = x.second + dir_y[i];
                if (tx < 0 || tx >= n || ty < 0 || ty >= m || ~dis[tx][ty] || !grid[tx][ty]) continue;
                dis[tx][ty] = dis[x.first][x.second] + 1;
                q.push(make_pair(tx, ty));
                if (grid[tx][ty] == 1) {
                    cnt -= 1;
                    ans = dis[tx][ty];
                    if (!cnt) break;
                }
            }
        }
        return cnt ? -1 : ans;
    }
};
```

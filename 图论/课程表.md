## 课程表

### 问题

你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1` 。

在选修某些课程之前需要一些先修课程。 先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]` ，表示如果要学习课程 `ai` 则 **必须** 先学习课程 `bi` 。

- 例如，先修课程对 `[0, 1]` 表示：想要学习课程 `0` ，你需要先完成课程 `1` 。

请你判断是否可能完成所有课程的学习？如果可以，返回 `true` ；否则，返回 `false` 。

提示：

- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= 5000`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `prerequisites[i]` 中的所有课程对 **互不相同**

### 思路一（bfs）

将所有课程抽象为图上的点，条件学习课程 $a_i$ 必须学习课程 $b_i$ 视为有向边 $b_i\rightarrow a_i$，若有向图无环，则至少存在一种方案可以遍历图上所有的点，该方案是一个拓扑序。因此本题的解决思路为在拓扑排序过程中判环，过程如下：

1. 首先统计每个节点的入度，初始将所有入度为 0 的点入队。
2. 取出队首节点 $u$，遍历从 $u$ 出发的所有有向边 $u\rightarrow v$，节点 $v$ 的入度减一，若 $v$ 的入度减为零则将其入队。
3. 重复步骤 2，直到队列为空。

在上述过程中统计入队（出队）节点的个数 $cnt$，当且仅当 $cnt=n$ 该图的拓扑序有解。

#### 时空复杂度

时间复杂度 $O(n+m)$

空间复杂度 $O(n+m)$

#### 代码

```C++
class Solution {
public:
    bool topSort(int n, vector<vector<int>> &graph) {
        vector<int> in(n, 0);
        for (int i = 0; i < n; i++) {
            for (auto v: graph[i]) {
                in[v]++;
            }
        }
        queue<int> q;
        for (int i = 0; i < n; i++) {
            if (in[i] == 0) {
                q.push(i);
            }
        }
        int cnt = 0;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            ++cnt;
            for (auto v : graph[u]) {
                if (--in[v] == 0) {
                    q.push(v);
                }
            }
        }
        if (cnt < n) return false;
        return true;
    }

    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> graph(numCourses);
        for (auto &v : prerequisites) {
            graph[v[1]].push_back(v[0]);
        }
        return topSort(numCourses, graph);
    }
};
```

### 思路二（dfs）

可以将深度优先搜索的流程与拓扑排序的求解联系起来，用一个栈来存储所有**已经搜索完成的节点**。

假设当前搜索到了节点 $u$，如果它的所有相邻节点都已经搜索完成，那么这些节点都已经在栈中了，此时把 $u$ 入栈。可以发现从栈顶往栈底的顺序看，由于 $u$ 处于栈顶的位置，那么 $u$ 出现在所有满足 $u \rightarrow v$ 的相邻节点 $v$​ 的前面，满足拓扑排序的要求。

对图中任意一个节点，在搜索过程中有三种状态：

- 未搜索
- 搜索中
- 已完成

在每一轮搜索开始，任取一个**未搜索**的节点开始深度优先搜索：

- 将当前节点 $u$ 标记为搜索中，遍历该节点的每一个相邻节点 $v$
  - 若 $v$ 的状态是未搜索，那么开始搜索 $v$；
  - 若 $v$ 的状态是搜索中，那么找到了图中的一个环，即不存在拓扑排序；
  - 若 $v$ 为已完成，说明 $v$ 已经在栈中了，而 $u$ 还不在栈中，$u$ 无论何时入栈都不会影响到 $(u, v)$ 之间的拓扑关系，不用进行任何操作。
- 当 $u$ 的所有相邻节点都为已完成时，将 $u$ 放入栈中，并标记状态为已完成

在整个深度优先搜索的过程结束后，如果图中不含环，那么栈中存储这所有的 $n$ 个节点，从栈顶到栈底的顺序即为一种拓扑排序。

#### 时空复杂度

时间复杂度 $O(n+m)$

空间复杂度 $O(n+m)$

#### 代码

```C++
class Solution {
public:
    enum status {
        INACTIVE,   // 未搜索
        ACTIVE,     // 搜索中
        FINISHED    // 已完成
    };

    vector<status> vis;
    vector<vector<int>> graph;
    vector<int> st;

    bool dfs(int u) {
        vis[u] = ACTIVE;
        for (auto v : graph[u]) {
            if (vis[v] == ACTIVE) return false;
            if (vis[v] == INACTIVE && !dfs(v))	// 如果后继未被访问，访问后继返回假，也是失败
                return false;
        }
        vis[u] = FINISHED;
        st.push_back(u);
        return true;
    }

    bool topSort(int n) {
        vis.resize(n, INACTIVE);
        for (int i = 0; i < n; i++) {
            if (vis[i] == INACTIVE) {
                bool ret = dfs(i);
                if (!ret) return ret;
            }
        }
        return true;
    }

    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        graph.resize(numCourses);
        for (auto &v : prerequisites) {
            graph[v[1]].push_back(v[0]);
        }
        return topSort(numCourses);
    }
};
```

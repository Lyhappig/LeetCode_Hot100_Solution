## 最长递增子序列

### 问题

给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

提示：

- `1 <= nums.length <= 2500`
- $-10^4\leq$ `nums[i]` $\leq 10^4$

### 思路一（DP）

设 $d[i]$ 表示以 $i$ 结尾的最长上升子序列的长度，考虑从 $1 \sim j,j < i$ 的状态进行转移，则
$$
d[i] = \max_\limits{1 \leq j <i, a[j]<a[i]}\{d[j]+1\}
$$
最终答案为
$$
\max_\limits{1 \leq i \leq n}\{ d[i]\}
$$

#### 时空复杂度

时间复杂度 $O(n^2)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int ans = 1, n = nums.size();
        vector<int> d(n + 1, 1);
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j < i; j++) {
                if (nums[j - 1] < nums[i - 1]) d[i] = max(d[i], d[j] + 1);
                ans = max(ans, d[i]);
            }
        }
        return ans;
    }
};
```

### 思路二（DP优化）

设 $f_k$ 代表**长度为 $k$ 的所有子序列中，结尾数的最小值**。

**引理：**随着 $k$ 的增大，$f_k$ 一定单调递增，即 $\forall j < i,f_j < f_i$

**反证法**：假设 $j < i, f_j \geq f_i$，那么一定可以从一个长度为 $i$ 的子序列中挑选出长度为 $j$ 的子序列使得它的结尾同样是 $f_i$。这和假设相矛盾，故原命题成立。

枚举序列中的每一个数 $a_i$ 来更新 $f$。因为 $f$ 是单调递增的，所以对于 $f_k \leq a_i$，那么长度为 $k$ 的子序列一定可以被构造出来。在更新数组 $f$ 时，要找到**尽可能小的 $f_k$ 满足 $a_i < f_k$**。最终 $\max\{k\}$ 就是最长上升子序列的长度。

#### 时空复杂度

时间复杂度 $O(n \log n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        vector<int> f;
        int ans = 0;
        for (int i = 0; i < nums.size(); i++) {
            auto pos = lower_bound(f.begin(), f.end(), nums[i]);
            if (pos == f.end()) {
                f.push_back(nums[i]);
            } else {
                *pos = nums[i];
            }
        }
        return (int) f.size();
    }
};
```

### 思路三（树状数组）

根据方法一中的递推式：
$$
d[i] = \max_\limits{1 \leq j < i, a[i] < a[i]}\{d[j]+1\}
$$
不难发现对于原序列每个元素，只需要将比它小的所有符合 $1 \leq j < i ~~ \&\& ~~ a[j]<a[i]$ 的 $d[j]$ 的最大值求出来，因此**最长上升子序列实际上就是求最多有多少元素它们的下标和权值同时满足单调递增**，这是一个二维偏序问题。

于是将数组的每一个元素保存下标，然后按照权值从小到大排序。接着按从小到大的顺序枚举排序后的数组，状态转移也就变成从之前的标号比它小的状态转移过来（当前是第 $i$ 个元素，那么求 $[1,i-1]$ 的最大的 $d[i]$）。因为每次只操作每个元素的前缀，因此只需要建立一个以下标为维护长度最大值的树状数组。

**注意**：如果出现相同权值的情况，按照序号从大到小可以保证所求为上升子序列，因为相同权值的数，前面的状态不能转移给后面，从大到小枚举就不会出现这种情况。

#### 时空复杂度

时间复杂度 $O(n \log n)$

空间复杂度 $O(n)$​

#### 代码

```C++
struct node {
    int id, v;

    bool operator<(const node &p) const {
        if (v == p.v) return id > p.id;
        return v < p.v;
    }
};

class Solution {
private:
    int n;
    vector<node> a;
    vector<int> t;
public:
    int lowbit(int x) {
        return x & -x;
    }

    void update(int i, int k) {
        while (i <= n) {
            t[i] = max(t[i], k);
            i += lowbit(i);
        }
    }

    int ask(int i) {
        int ans = 0;
        for (; i; i -= lowbit(i)) {
            ans = max(ans, t[i]);
        }
        return ans;
    }

    int lengthOfLIS(vector<int>& nums) {
        n = nums.size();
        a.resize(n);
        t.resize(n + 1, 0);
        for (int i = 1; i <= n; i++) {
            a[i - 1] = node{i, nums[i - 1]};
        }
        sort(a.begin(), a.end());
        for (int i = 0; i < n; i++) {
            update(a[i].id, ask(a[i].id) + 1);
        }
        return ask(n);
    }
};
```

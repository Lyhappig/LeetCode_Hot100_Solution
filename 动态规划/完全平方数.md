## 完全平方数

### 问题

给你一个整数 `n` ，返回 **和为 `n` 的完全平方数的最少数量**。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

提示：

- $1\leq n \leq 10^4$

### 思路一（完全背包）

问题可以抽象为：有 $\sqrt{n}$ 个物品集合，分别是 $S=\{1,4,9,\ldots,\sqrt{n}\cdot \sqrt{n}\}$，有一个容量为 $n$ 的背包，从这些物品中选出最少的数量恰好将背包装满，每种物品被认为是无限的。

设 $f[j]$ 表示容量为 $j$ 的背包装满物品的最少数量，那么有：
$$
f[j]=1+\min_{i\in S}\{f[j-i]\}
$$
其中 $f[0]=0$，其他初始状态为正无穷。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    int numSquares(int n) {
        vector<int> f(n + 1, 0x3f3f3f3f);
        f[0] = 0;
        for (int i = 1; i * i <= n; i++) {
            int v = i * i;
            for (int j = v; j <= n; j++) {
                f[j] = min(f[j], f[j - v] + 1);
            }
        }
        return f[n];
    }
};
```

### 思路二（数学）

四平方和定理：每个自然数最多表示为四个整数的平方和，即对于任意正整数 $n$，存在整数 $a,b,c,d$ 使得：
$$
n=a^2+b^2+c^2+d^2
$$
四平方和定理的结论：当且仅当 $n \neq4^k\times(8m+7)$ 时，$n$ 可以被表示为至多三个正整数的平方和。因此，当 $n=4^k\times(8m+7)$ 时，它只能被表示为四个正整数的平方和。

当 $n \neq4^k\times(8m+7)$ 时，答案只会是 $1,2,3$ 中的一个：

- 答案为 1 时，$n$ 一定是完全平方数；
- 答案为 2 时，则有 $n=a^2+b^2$，只需要枚举所有的 $1\leq a \leq \sqrt{n}$，判断 $n-a$ 是否为完全平方数即可；
- 答案为 3 时，即为排除了 $1,2,4$ 的情况。

#### 时空复杂度

时间复杂度 $O(\sqrt{n})$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    bool checkSquare(int x) {
        int y = sqrt(x);
        return x == y * y;
    }

    int numSquares(int n) {
        if (checkSquare(n)) {
            return 1;
        }
        int m = n;
        while (m % 4 == 0) m /= 4;
        if (m % 8 == 7) return 4;
        for (int i = 1; i * i <= n; i++) {
            if (checkSquare(n - i * i)) {
                return 2;
            }
        }
        return 3;
    }
};
```

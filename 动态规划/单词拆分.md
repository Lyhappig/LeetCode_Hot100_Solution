## 单词拆分

### 问题

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s` 则返回 `true`。

**注意：**不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

提示：

- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` 和 `wordDict[i]` 仅由小写英文字母组成
- `wordDict` 中的所有字符串 **互不相同**

### 思路（DP+哈希）

定义 $f[i]$ 表示字符串 $s$ 前 $i$ 个字符组成的字符串 $s[0 \ldots i−1]$ 是否能被拆分成若干个字典中出现的单词。

从前往后计算转移方程，枚举 $s[0\ldots i−1]$ 中的分割点 $j(0\leq j<i)$ ，检查 $s[0..j−1]$ 组成的字符串 $s_1$ 和 $s[j\ldots i−1]$ 组成的字符串 $s_2$ 是否都合法，如果两个字符串均合法，那么按照定义 $s_1,s_2$ 拼接成的字符串也同样合法。

字符串 $s_1$ 是否合法可以直接由 $f[j]$ 得知，而 $s_2$ 是否合法只需要检查其是否出现在字典中，因此得出如下转移方程：
$$
f[i]=f[j] \and check(s[j\ldots i−1])
$$

对于边界条件，定义 $f[0]=1$ 表示空串合法。检查一个字符串是否出现在给定的字符串列表里使用哈希表 $O(1)$ 判断。

#### 时空复杂度

时间复杂度 $O(n^2)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {    
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> st;
        for (auto &word : wordDict) {
            st.insert(word);
            if (word == s) return true;
        }
        int n = s.size();
        vector<bool> f(n + 1, false);
        f[0] = true;
        for (int i = 1; i <= n; i++) {
            for(int j = 0; j < i; j++) {
                if (f[j] && st.count(s.substr(j, i - j))) {
                    f[i] = true;
                    break;
                }
            }
        }
        return f[n];
    }
};
```

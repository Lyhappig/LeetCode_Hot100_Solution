## 爬楼梯

### 问题

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

提示：

- `1 <= n <= 45`

### 思路一（递推）

设 $f(x)$ 表示爬到第 $x$ 级台阶的方案数，考虑最后一步可能跨了一级台阶，也可能跨了两级台阶，转移方程为：

$$
f(x)=f(x−1)+f(x−2)
$$
由于 $f(x)$ 只和 $f(x−1)$ 与 $f(x−2)$ 有关，所以可以用「滚动数组思想」，设置两个变量仅表示前两个状态。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    int climbStairs(int n) {
        int a = 1, b = 1, ans = 1;
        for (int i = 2; i <= n; i++) {
            ans = a + b;
            a = b, b = ans;
        }
        return ans;
    }
};
```

### 思路二（矩阵快速幂）

对于齐次二阶递推式 $F(n) = a\cdot F(n-1) + b\cdot F(n-2)$，定义状态向量 $X_n=\left[ \begin{array}{ccc} F(n) \\ F(n-1)\end{array} \right]$，同时有 $X_{n-1}=\left[ \begin{array}{ccc} F(n-1) \\ F(n-2)\end{array} \right]$。通过构造一个二阶转移矩阵 $m$ 使得 $X_n=m\cdot X_{n-1}$。设特征矩阵 $m = \left[ \begin{array}{ccc} p & q \\ r & s \end{array} \right]$，那么有：

$$
\left[ \begin{array}{ccc} F(n) \\ F(n-1)\end{array} \right]=\left[ \begin{array}{ccc} p & q \\ r & s \end{array} \right]\left[ \begin{array}{ccc} F(n-1) \\ F(n-2)\end{array} \right]
$$
根据斐波那契数列的递推公式 $a=1,b=1$，可以求出 $p,q,r,s$，最终得到 $X_n$ 和向量矩阵 $[F(2), F(1)]^T$ 的关系：
$$
\left[ \begin{array}{ccc} F(n) \\ F(n-1)\end{array} \right]=\left[ \begin{array}{ccc} a & b \\ 1 & 0 \end{array} \right]^{n-2}\left[ \begin{array}{ccc} F(2) \\ F(1) \end{array} \right]
$$


这样可以使用矩阵快速幂来求解斐波那契数列的第 $n$ 项。

#### 时空复杂度

时间复杂度 $O(\log n)$

空间复杂度 $O(1)$​

#### 代码

```C++
struct Matrix {
    int n, m;
    long long matrix[3][3];

    Matrix() {}

    Matrix(int x, int y) {
        n = x, m = y;
        memset(matrix, 0, sizeof(matrix));
    }
};

class Solution {
public:
    Matrix mul(Matrix a, Matrix b) {
        Matrix ans(a.n, b.m);
        for (int i = 1; i <= ans.n; i++)
            for (int j = 1; j <= ans.m; j++)
                for (int k = 1; k <= a.m; k++) {
                    ans.matrix[i][j] += a.matrix[i][k] * b.matrix[k][j];
                }
        return ans;
    }

    Matrix qkp(Matrix mx, int n) {
        Matrix ans(mx.n, mx.m);
        for (int i = 1; i <= mx.n; i++) {
            ans.matrix[i][i] = 1;
        }
        while (n) {
            if (n & 1) {
                ans = mul(ans, mx);
            }
            mx = mul(mx, mx);
            n >>= 1;
        }
        return ans;
    }

    int climbStairs(int n) {
        ++n;
        if (n == 1 || n == 2) return 1;
        Matrix a(2, 2);
        a.matrix[1][1] = 1, a.matrix[1][2] = 1;
        a.matrix[2][1] = 1, a.matrix[2][2] = 0;
        Matrix b(2, 1);
        b.matrix[1][1] = 1, b.matrix[2][1] = 1;
        Matrix ans = mul(qkp(a, n - 2), b);
        return ans.matrix[1][1];
    }
};
```

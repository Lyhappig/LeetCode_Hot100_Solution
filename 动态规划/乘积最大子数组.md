## 乘积最大子数组

### 问题

给你一个整数数组 `nums` ，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 **32-位** 整数。

提示：

- $1\leq$ `nums.length` $\leq 2\times 10^4$
- $-10 \leq$ `nums[i]` $\leq 10$
- `nums` 的任何子数组的乘积都 **保证** 是一个 **32-位** 整数

### 思路一（DP）

如果当前位置是一个正数，那么期望以它前一个位置结尾的某个段的积也是个正数，并且希望它尽可能地大，可以采用类似**最大子序和**的做法。但如果当前位置是一个负数的话，那么期望以它前一个位置结尾的某个段的积也是个负数，并且这个积需要尽可能地小，这样就可以负负得正。因此维护 $f_2[i]$  表示以第 $i$ 个元素结尾的乘积最小子数组的乘积，那么得到这样的动态规划转移方程：
$$
f_1[i]=\max_{1\leq i\leq n}\{f_1[i-1] \times a_i, f_2[i-1] \times a_i, a_i\}\\
f_2[i]=\min_{1\leq i\leq n}\{f_1[i-1] \times a_i, f_2[i-1] \times a_i, a_i\}
$$
由于第 $i$ 个状态只和第 $i-1$ 个状态有关，根据滚动数组的思想，可以只用两个变量维护 $i-1$ 时刻的状态。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int maxF = nums[0], minF = nums[0], ans = nums[0];
        for (int i = 1; i < nums.size(); i++) {
            int t1 = maxF, t2 = minF;
            maxF = max(nums[i], max(t1 * nums[i], t2 * nums[i]));
            minF = min(nums[i], min(t1 * nums[i], t2 * nums[i]));
            ans = max(ans, maxF);
        }
        return ans;
    }
};
```

### 思路二（零分割+负数计数）

- 将数组按 `0` 切分成若干不含 `0` 的子段。
- 在每个子段内，统计负数的个数：
  - 若负数个数为偶数，整个子段的乘积即为候选答案。
  - 若为奇数，答案要么是“第一个负数右侧的子段乘积”，要么是“最后一个负数左侧的子段乘积”。

具体做法：正反两次遍历覆盖所有可能的连续子数组，遇到 `0` 时乘积重置为 `1`，相当于从下一个元素重新开始计算子数组乘积。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int ans = nums[0];
        int res = 1;
        for (int i = 0; i < nums.size(); i++) {
            res = res * nums[i];
            ans = max(ans, res);
            if (nums[i] == 0) {
                res = 1;
            }
        }
        res = 1;
        for (int i = nums.size() - 1; i >= 0; i--) {
            res = res * nums[i];
            ans = max(ans, res);
            if (nums[i] == 0) {
                res = 1;
            }
        }
        return ans;
    }
};
```

### 思路三（分治法）

将数组分为左右两部分，最大乘积子数组要么**完全在左半部分**，要么**完全在右半部分**，要么**跨越中点**。

对于跨越中点的情况：从中点向左右两侧扩展，分别维护左侧的**最大/最小乘积**和右侧的**最大/最小乘积**，即包含左端点的连续子数组最大/最小乘积、包含右端点的连续子数组最大/最小乘积。由于乘法存在负负得正，跨越中点的最大值为如下二者的最大值：

1. 左侧最大 乘以 右侧最大
2. 左侧最小 乘以 右侧最小

为了 $O(1)$ 维护左侧/右侧的最大/最小乘积，需要再维护区间乘积，左侧最大乘积为如下三者的最大值，其他情况同理：

1. 左侧最大
2. 左侧区间乘积 乘以 右侧最大
3. 左侧区间乘积 乘以 右侧最小

#### 时空复杂度

时间复杂度 $O(n \log n)$

空间复杂度 $O(\log n)$

#### 代码

```c++
struct DfsResult {
    int max_factor;  // 区间的乘积最大子数组
    int tot_factor;  // 区间的乘积
    int left_max_factor;  // 从左到右的乘积最大连续子数组
    int left_min_factor;  // 从左到右的乘积最小连续子数组
    int right_max_factor;  // 从右到左的乘积最大连续子数组
    int right_min_factor;  // 从右到左的乘积最小连续子数组
};

class Solution {
public:
    DfsResult dfs(vector<int> &nums, int l, int r) {
        if (l == r) {
            DfsResult result{nums[l], nums[l], nums[l], nums[l], nums[l], nums[l]};
            return result;
        }
        int mid = (l + r) >> 1;
        auto left_result = dfs(nums, l, mid);
        auto right_result = dfs(nums, mid + 1, r);
        DfsResult result;
        result.max_factor = max(left_result.right_max_factor * right_result.left_max_factor, left_result.right_min_factor * right_result.left_min_factor);
        result.max_factor = max(result.max_factor, max(left_result.max_factor, right_result.max_factor));
        result.tot_factor = left_result.tot_factor * right_result.tot_factor;
        result.left_max_factor = max(left_result.left_max_factor, max(left_result.tot_factor * right_result.left_max_factor, left_result.tot_factor * right_result.left_min_factor));
        result.left_min_factor = min(left_result.left_min_factor, min(left_result.tot_factor * right_result.left_max_factor, left_result.tot_factor * right_result.left_min_factor));
        result.right_max_factor = max(right_result.right_max_factor, max(left_result.right_max_factor * right_result.tot_factor, left_result.right_min_factor * right_result.tot_factor));
        result.right_min_factor = min(right_result.right_min_factor, min(left_result.right_max_factor * right_result.tot_factor, left_result.right_min_factor * right_result.tot_factor));
        return result;
    }

    int maxProduct(vector<int>& nums) {
        auto result = dfs(nums, 0, nums.size() - 1);
        return result.max_factor;
    }
};
```

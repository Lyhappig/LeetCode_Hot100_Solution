## 分割等和子集

### 问题

给你一个 **只包含正整数** 的 **非空** 数组 `nums` 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

提示：

- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`

### 思路（01背包）

若整个数组求和结果为奇数，则无解，否则问题变成：给出 $n$ 个数，每个数选或不选，问某个数 $m$ 是否可以被给出的若干个数求和得到。

经典的 01 背包模型，对于每个数 $j$ 可以遍历所有状态 $j-a_i$，若 $j - a[i]$ 可以被表示出来那么 $j$ 也可以被表示出来，使用或运算进行状态转移。

此外，状态转移数组 $d$ 还可以使用 bitset 优化，当前状态的 $[a_i, m - a_i]$ 都要和上一个状态的这部分求或运算，因为上一个状态的 $[0, a_i]$ 不需要状态转移而保留，因此状态转移为 $d ~|= (d << a_i)$。

#### 时空复杂度

时间复杂度 $O(n \cdot m)$，其中 $m=\sum nums[i]$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int n = nums.size();
        int sum = 0;
        for (int i = 0; i < n; i++) sum += nums[i];
        if (sum & 1) return false;
        sum /= 2;
        vector<bool> f(sum + 1, false);
        f[0] = true;
        for (int i = 0; i < n; i++) {
            for (int j = sum; j >= nums[i]; j--) {
                f[j] = f[j] | f[j - nums[i]];
            }
        }
        return f[sum];
    }
};
```

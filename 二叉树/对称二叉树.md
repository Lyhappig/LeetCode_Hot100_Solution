## 对称二叉树

### 问题

给你一个二叉树的根节点 `root` ， 检查它是否轴对称。

**注意：**

![img](https://pic.leetcode.cn/1698026966-JDYPDU-image.png)

提示：

- 树中节点数目在范围 `[1, 1000]` 内
- `-100 <= Node.val <= 100`

### 思路一（递归）

对称二叉树满足：

- 对称二叉树的根节点一定是对称的
- 对称二叉树根节点的左右孩子节点的值相同
  - 左孩子的左子树和右孩子的右子树是对称的
  - 左孩子的右子树和右孩子的左子树是对称的

本质是对同一棵树划分为关于对称轴的两个镜像，遍历两个镜像的子树是否始终满足相等。因此需要有两个指针分别记录对称的两个节点，自底向上返回比较两个镜像子树的结果。**可以理解为树上双指针**。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    bool dfs(TreeNode* LNode, TreeNode* RNode) {
        if(!LNode && !RNode) return true;
        if(!LNode || !RNode) return false;
        return LNode->val == RNode->val && dfs(LNode->left, RNode->right) && dfs(LNode->right, RNode->left);
    }

    bool isSymmetric(TreeNode* root) {
        return dfs(root, root);
    }
};
```

### 思路二（层次遍历）

一种直观简单的思路是：检查树的每层是否是"回文"（对称）的。

还有一种更简单的方法，类似第一种思路的双指针递归，初始将轴对称的根节点入队两次，代表两个在对称轴两侧移动的指针

每次取出两个轴对称的节点 $l,r$

1. 检查 $l,r$ 是否均为有效/无效节点，两个有效节点的值是否相同
2. 将 $l$ 的左孩子和 $r$ 的右孩子入队，作为下一层要比较的相邻轴对称节点
3. 将 $l$ 的右孩子和 $r$ 的左孩子入队，作为下一层要比较的相邻轴对称节点

重复上述过程，直到队列为空且任何两两节点都相同，那么该二叉树是镜像的。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    bool isSymmetric(TreeNode* root) {
        queue<TreeNode*> q;
        q.push(root);
        q.push(root);
        while(!q.empty()) {
            auto l = q.front(); q.pop();
            auto r = q.front(); q.pop();

            if(!l && !r) continue;
            if(!l || !r) return false;
            if(l->val != r->val) return false;

            q.push(l->left);
            q.push(r->right);
            q.push(l->right);
            q.push(r->left);
        }
        return true;
    }
};
```

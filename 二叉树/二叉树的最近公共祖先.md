## 二叉树的最近公共祖先

### 问题

给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

提示：

- 树中节点数目在范围 $[2, 10^5]$ 内。
- $-10^9 \leq$ `Node.val` $\leq 10^9$
- 所有 `Node.val` 互不相同 。
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中。

### 思路一（递归）

设递归函数的返回值 $b_1,b_2$ 分别代表 $p,q$ 是否在在节点 $i$ 为根的子树中，最近公共祖先一定满足如下条件之一：

- $b_1 = 1,b_2=1$
- $b_1=1, i=q$
- $i=p,b_2=1$

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$

```c++
class Solution {
private:
    TreeNode* ans;
public:
    bool dfs(TreeNode* root, TreeNode* p, TreeNode* q) {
        if(!root) return false;
        bool res1 = dfs(root->left, p, q);
        bool res2 = dfs(root->right, p, q);
        if((res1 && res2) || ((root->val == p->val || root->val == q->val) && (res1 || res2))) {
            ans = root;
        }
        return res1 || res2 || (root->val == p->val || root->val == q->val);
    }

    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        dfs(root, p, q);
        return ans;
    }
};
```

### 思路二（递归）

递归对二叉树进行先序遍历，当遇到节点 $p$ 或 $q$ 时返回，设 $l,r$ 为分别递归左右子树的返回值：

- 若 $l,r$ 均为空，说明 $root$ 的左右子树均不包含 $p,q$，最近公共祖先一定不在该子树上，返回空
- 若 $l,r$ 同时不为空，说明 $p,q$ 分别在 $root$ 的异侧，因此 $root$ 为最近公共祖先
- 若 $l,r$ 其中一个为空，那么返回非空的节点

上述的第三种情况恰好覆盖了 $p$ 或 $q$ 为最近公共祖先的情况

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$

```c++
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if(!root || root->val == p->val || root->val == q->val) return root;
        auto LNode = lowestCommonAncestor(root->left, p, q);
        auto RNode = lowestCommonAncestor(root->right, p, q);
        if (LNode == nullptr) return RNode;
        if (RNode == nullptr) return LNode;
        return root;
    }
};
```

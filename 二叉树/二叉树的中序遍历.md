## 二叉树的中序遍历

### 问题

给定一个二叉树的根节点 `root` ，返回它的 **中序** 遍历 。

提示：

- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

### 思路一（递归）

左-右-中

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
private:
    vector<int> ans;
public:
    void dfs(TreeNode* root) {
        if (!root) return;
        dfs(root->left);
        ans.push_back(root->val);
        dfs(root->right);
    }

    vector<int> inorderTraversal(TreeNode* root) {
        ans.clear();
        dfs(root);
        return ans;
    }
};
```

### 思路二（迭代）

迭代的核心思想是 **采用栈模拟递归**。对于任意一棵树，都将其抽象为 **(左子树，中节点，右子树)**，也可以简称为 **左-中-右** 三个 "节点"。

遍历一棵树时，按照递归的思路理解，分为 进入 和 回溯 两个阶段，用栈模拟可以理解为 "两次入栈"，第一次入栈时是 **整个子树入栈**，通过栈中序遍历该子树，就要对其进行 **展开**。对于任意一棵树，中序遍历都是先递归左子树，因此需要按照 **右-中-左** 的顺序入栈展开。

采用变量 flag 标记节点两次入栈的过程，flag = 0 代表第一次入栈，flag = 1 代表第二次入栈。首先根节点标记为 0 入栈，迭代取出栈顶节点时：

- 当 flag = 0 时，代表递归进入的过程，按照 右-中-左 的顺序将该子树入栈展开；
- 当 flag = 1 时，代表递归回溯的过程，将栈顶节点输出。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> ans;
        if (root == nullptr) {
            return ans;
        }
        vector<pair<TreeNode*, bool>> stack;
        stack.push_back({root, false});
        while (!stack.empty()) {
            TreeNode *now = stack.back().first;
            bool flag = stack.back().second;
            stack.pop_back();
            if (now == nullptr) continue;
            if (!flag) {
                stack.push_back({now->right, false});
                stack.push_back({now, true});
                stack.push_back({now->left, false});
            } else {
                ans.push_back(now->val);
            }
        }
        return ans;
    }
};
```

### 思路三（Moris 遍历）

Morris 算法能够将非递归的中序遍历，空间复杂度降低到 $O(1)$，算法流程如下：

1. 如果 $x$ 没有左孩子，打印 $x$ 的值，再访问 $x$ 的右孩子
2. 如果 $x$ 有左孩子，找到 $x$ 左子树上最右的节点（即**左子树中序遍历的最后一个节点，在当前子树中序遍历中 $x$ 的前驱节点**），将其记为 `predecessor`，根据 `predecessor` 的右孩子是否为空，进行如下操作：
   - 若 `predecessor` 的右孩子为空，则将其右孩子指向 $x$，然后访问 $x$ 的左孩子；
   - 若  `predecessor` 的右孩子不为空，则此时其右孩子指向 $x$，说明已经遍历完 $x$ 的左子树，将 `predecessor` 的右孩子置空，打印  $x$ 的值，然后访问 $x$ 的右孩子
3. 重复上述过程，直到访问完整棵树。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> res;
        TreeNode *predecessor = nullptr;

        while (root != nullptr) {
            if (root->left != nullptr) {
                // predecessor 节点就是当前 root 节点向左走一步，然后一直向右走至无法走为止
                predecessor = root->left;
                while (predecessor->right != nullptr && predecessor->right != root) {
                    predecessor = predecessor->right;
                }
                // 让 predecessor 的右指针指向 root，继续遍历左子树
                if (predecessor->right == nullptr) {
                    predecessor->right = root;
                    root = root->left;
                }
                // 说明左子树已经访问完了，我们需要断开链接
                else {
                    res.push_back(root->val);
                    predecessor->right = nullptr;
                    root = root->right;
                }
            }
            // 如果没有左孩子，则直接访问右孩子
            else {
                res.push_back(root->val);
                root = root->right;
            }
        }
        return res;
    }
};
```

## 验证二叉搜索树

### 问题

给你一个二叉树的根节点 `root` ，判断其是否是一个有效的二叉搜索树。

**有效** 二叉搜索树定义如下：

- 节点的左子树只包含小于当前节点的数。
- 节点的右子树只包含大于当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

提示：

- 树中节点数目范围在 $[1, 10^4]$ 内
- $-2^{31} \leq$ `Node.val` $\leq 2^{31} - 1$

### 思路一（递归）

根据二叉搜索树的性质，设计递归函数：

- 判断根节点是否符合值域区间 $[l, r]$
- 递归判断左子树是否符合值域区间 $[l, root \rightarrow val]$ 
- 递归判断左子树是否符合值域区间 $[l, root \rightarrow val]$ 

初始整个值域区间为负无穷到正无穷

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    bool dfs(TreeNode* root, long long l, long long r) {
        if(!root) return true;
        if(root->val <= l || root->val >= r) return false;
        return dfs(root->left, l, root->val) && dfs(root->right, root->val, r);
    }

    bool isValidBST(TreeNode* root) {
        if(!root) return true;
        long long inf = 1e18;
        return dfs(root, -inf, inf);
    }
};
```

### 思路二（中序遍历）

二叉搜索树按照中序遍历展开后，一定是有序序列。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
private:
    vector<int> res;
public:
    void dfs(TreeNode* root) {
        if(!root) return;
        dfs(root->left);
        res.push_back(root->val);
        dfs(root->right);
    }

    bool isValidBST(TreeNode* root) {
        dfs(root);
        for(int i = 1; i < res.size(); i++) {
            if(res[i] <= res[i - 1]) return false;
        }
        return true;
    }
};
```

## 将有序数组转换为二叉搜索树

### 问题

给你一个整数数组 `nums` ，其中元素已经按 **升序** 排列，请你将其转换为一棵平衡二叉搜索树

- $1 \leq$ `nums.length` $\leq 10^4$
- $-10^4 \leq$ `nums[i]` $\leq 10^4$
- `nums` 按 **严格递增** 顺序排列

### 思路（递归）

给定二叉搜索树的中序遍历，是否可以唯一地确定二叉搜索树？答案是否定的。如果没有要求二叉搜索树的高度平衡，则任何一个数字都可以作为二叉搜索树的根节点，因此可能的二叉搜索树有多个。如果增加一个限制条件，即要求二叉搜索树的高度平衡，是否可以唯一地确定二叉搜索树？答案仍然是否定的。

![fig2](https://assets.leetcode-cn.com/solution-static/108/108_fig2.png)

「平衡」要求它是一棵空树或它的左右两个子树的高度差的绝对值不超过 1，容易想到一种思路：左右子树的大小越「平均」，这棵树就越平衡。这样想法下贪心建树的做法为：

- 令 $mid = \lfloor \frac{l + r}{2} \rfloor$，即中心位置作为当前子树（代表序列的一段连续区间）的根节点；
- 递归地将区间 $[l,mid−1]$ 作为当前节点的左子树；
- 递归地将区间 $[mid+1,r]$ 作为当前节点的右子树。

**引理一**

长度为 $k$ 的区间与长度为 $k+1$ 的区间（其中 $k\geq 1$）按照以上方法构造出的二叉搜索树的最大高度差不超过 1。

**数学归纳法证明**

假设我们要讨论的区间长度为 $k$，证明过程如下：

- $k=1,k=2$ 时显然成立；
- 假设 $k=m$ 和 $k=m+1$ 时正确性成立：
  - 根据「引理 一」，长度为 $m$ 和 $m+1$ 的区间构造出的子树都是平衡的，并且它们的高度差不超过 1；
  - 当 $k=2(m+1)−1$ 时，创建出的节点的值等于第 $m+1$ 个元素的值，它的左边和右边各有长度为 m 的区间，根据「假设推论」，$k=2(m+1)−1$ 时构造出的左右子树都是平衡树，且树形完全相同，故高度差为 0，所以 $k=2(m+1)−1$ 时，正确性成立；
  - 当 $k=2(m+1)$ 时，创建出的节点的值等于第 $m+1$ 个元素的值，它的左边的区间长度为 $m$，右边区间的长度为 $m+1$，那么 $k=2(m+1)$ 时构造出的左右子树都是平衡树，且高度差不超过 1，所以 $k=2(m+1)$ 时，正确性成立；

故在 $k \geq 1$ 时，正确性成立，证毕。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(\log n)$​

#### 代码

```C++
class Solution {
public:
    TreeNode* build(int l, int r, vector<int>& nums) {
        if(l > r) return nullptr;
        int mid = (l + r) >> 1;
        TreeNode* now = new TreeNode(nums[mid]);
        now->left = build(l, mid - 1, nums);
        now->right = build(mid + 1, r, nums);
        return now;
    }

    TreeNode* sortedArrayToBST(vector<int>& nums) {
        return build(0, nums.size() - 1, nums);
    }
};
```

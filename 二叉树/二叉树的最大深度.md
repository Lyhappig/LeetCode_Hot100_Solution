## 二叉树的最大深度

### 问题

给定一个二叉树 `root` ，返回其最大深度。

二叉树的 **最大深度** 是指从根节点到最远叶子节点的最长路径上的节点数。

提示：

- 树中节点的数量在 $[0, 10^4]$ 区间内。
- `-100 <= Node.val <= 100`

### 思路一（递归）

递归的思路在于自底向上，每个节点的深度取决于递归的深度。递归结束的条件为空节点返回 0

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
private:
    int ans;
public:
    int maxDepth(TreeNode* root) {
        if (!root) return 0;
        return max(maxDepth(root->left), maxDepth(root->right)) + 1;
    }
};
```

### 思路二（栈模拟递归）

采用栈模拟递归的思路是自顶向下，每个节点的深度取决于从根节点到它的距离。因为每个节点都会入栈两次，在第二次入栈展开时确定子节点的深度，出栈时更新最大深度。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
struct node {
    TreeNode* tree_node;
    int flag;
    int depth;
};

class Solution {
public:
    int maxDepth(TreeNode* root) {
        stack<node> st;
        st.push({root, 0, 1});
        int ans = 0;
        while (!st.empty()) {
            auto now = st.top();
            st.pop();
            if (!now.tree_node) continue;
            if (!now.flag) {
                st.push({now.tree_node->right, false, now.depth + 1});
                st.push({now.tree_node, true, now.depth});
                st.push({now.tree_node->left, false, now.depth + 1});
            } else {
                ans = max(ans, now.depth);
            }
        }
        return ans;
    }
};
```

### 思路三（层序遍历）

层序遍历的思路也属于自顶向下，只是按照层次序列在队列中展开。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    int maxDepth(TreeNode* root) {
        queue<pair<TreeNode*, int>> q;
        q.push({root, 1});
        int ans = 0;
        while (!q.empty()) {
            auto now = q.front();
            q.pop();
            auto tree_node = now.first;
            auto depth = now.second;
            if (!now.first) continue;
            ans = max(ans, now.second);
            q.push({tree_node->left, depth + 1});
            q.push({tree_node->right, depth + 1});
        }
        return ans;
    }
};
```

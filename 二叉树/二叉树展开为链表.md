## 二叉树展开为链表

### 问题

给你二叉树的根结点 `root` ，请你将它展开为一个单链表：

- 展开后的单链表应该同样使用 `TreeNode` ，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null` 。
- 展开后的单链表应该与二叉树先序遍历顺序相同。

注意：

你可以使用原地算法（`O(1)` 额外空间）展开这棵树吗？

提示：

- 树中结点数在范围 `[0, 2000]` 内
- `-100 <= Node.val <= 100`

### 思路一（迭代）

一种简单的思路是，先对二叉树进行先序遍历，放到数组中，再遍历一次数组将二叉树节点依次展开成链表。

先序遍历的递归过程中进行展开会导致丢失递归信息，而先序遍历的迭代写法会将遍历序列逆向入栈，并按顺序出栈，因此可以在出栈时对每个二叉树节点进行展开。

采用染色标记法的迭代模拟递归，每个节点入栈两次：

- 第一次入栈时将节点标记为 0，代表节点下的整个子树入栈；
- 第二次入栈时，将子树划分为"根节点-左子树-右子树"三部分，并按照"右子树-左子树-根节点"的顺序入栈。入栈时根节点标记为 1，左孩子和右孩子都标记为 0

当某棵子树的根节点第二次出栈后，若栈不为空，那么栈顶节点就是"左子树"的根节点，按照题意应该作为根节点的右子树，并将其左子树置为空。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$

```c++
class Solution {
public:
    void flatten(TreeNode* root) {
        if (!root) return;
        vector<pair<TreeNode*, bool>> stack_;
        stack_.push_back({root, false});
        while (!stack_.empty()) {
            auto now = stack_.back().first;
            auto flag = stack_.back().second;
            stack_.pop_back();
            if (!flag) {
                if (now->right != nullptr) {
                    stack_.push_back({now->right, false});
                }
                if (now->left != nullptr) {
                    stack_.push_back({now->left, false});
                }
                stack_.push_back({now, true});
            } else {
                if (!stack_.empty()) {
                    now->left = nullptr;
                    now->right = stack_.back().first;
                }
            }
        }
    }
};
```

### 思路二（递归）

递归求解二叉树展开，定义递归函数的返回值为展开后链表的**最后一个节点**：

- 当子树根节点没有左右孩子时，返回根节点
- 当子树根节点只有左孩子，没有右孩子时，将左孩子作为根节点的右孩子，并**递归展开左子树**，并返回左子树链表的尾部 `left_last`
- 当子树根节点没有左孩子，只有右孩子时，**递归展开右子树**，并返回右子树链表的尾部 `right_last`
- 当子树根节点既有左孩子，又有右孩子时：
  - 将左孩子作为根节点的右孩子，先**递归展开左子树**，并记录展开后左子树链表的尾部 `left_last`
  - 将右孩子作为 `left_last` 的右孩子，递归展开右子树，并返回右子树链表的尾部 `right_last`

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$

```c++
class Solution {
public:
    TreeNode* dfs(TreeNode* root) {
        auto left = root->left;
        auto right = root->right;
        auto last = root;
        root->left = nullptr;
        if (left != nullptr) {
            root->right = left;
            last = dfs(left);
        }
        if (right != nullptr) {
            last->right = right;
            last = dfs(right);
        }
        return last;
    }

    void flatten(TreeNode* root) {
        if (!root) return;
        dfs(root);
    }
};
```

### 思路三（寻找前驱）

注意到前序遍历访问各节点的顺序是根节点、左子树、右子树。如果一个节点的左子节点为空，则该节点不需要进行展开操作。如果一个节点的左子节点不为空，则该节点的左子树中的最后一个节点被访问之后，该节点的右子节点被访问。该节点的左子树中最后一个被访问的节点是左子树中的最右边的节点，也是该节点的前驱节点。类似 Moris 中序遍历二叉树的过程，问题转化成寻找当前节点的前驱节点。

对于当前节点，如果其左子节点不为空，则在其左子树中找到最右边的节点，作为前驱节点，将当前节点的右子节点赋给前驱节点的右子节点，然后将当前节点的左子节点赋给当前节点的右子节点，并将当前节点的左子节点设为空。

对当前节点处理结束后，链表头到当前节点都已经展开完毕，只需要迭代处理链表下一个节点。重复此过程直到所有节点都处理结束。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$

```c++
class Solution {
public:
    void flatten(TreeNode* root) {
        TreeNode* cur;
        while (root) {
            if (root->left != nullptr) {
                cur = root->left;
                while (cur->right != nullptr) {
                    cur = cur->right;
                }
                cur->right = root->right;
                root->right = root->left;
                root->left = nullptr;
            }
            root = root->right;
        }
    }
};
```

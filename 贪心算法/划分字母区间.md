## 划分字母区间

### 问题

给你一个字符串 `s` 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，字符串 `"ababcc"` 能够被分为 `["abab", "cc"]`，但类似 `["aba", "bcc"]` 或 `["ab", "ab", "cc"]` 的划分是非法的。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 `s` 。

返回一个表示每个字符串片段的长度的列表。

提示：

- `1 <= s.length <= 500`
- `s` 仅由小写英文字母组成

### 思路（贪心）

预处理字符串，记录每个位置的后缀中下一个相同字符的位置 $suf[i]$。维护一个字母区间 $l,r$，从前向后遍历字符串：

- 若当前字符 $s_i$ 后缀中下一个相同字符位置 $suf[i]$ 小于区间右端点 $r$，更新 $r=suf[i]$；
- 若当前字符 $s_i$ 即为当前区间的边界 $r$，则切分一个长度为 $r-l$ 的字母区间，并更新下一个区间的起点 $l=i$。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    vector<int> partitionLabels(string s) {
        vector<int> suf(s.size());
        for (int i = 0; i < s.size(); i++) suf[i] = i;
        int pos[26] = {-1};
        for (int i = s.size() - 1; i >= 0; i--) {
            int& x = pos[s[i] - 'a'];
            x = max(x, i);
            suf[i] = x;
        }
        int pre = -1, cur = 0;
        vector<int> ans;
        for (int i = 0; i < s.size(); i++) {
            if (cur < suf[i]) {
                cur = suf[i];
            }
            if (cur == i) {
                ans.push_back(cur - pre);
                pre = cur;
            }
        }
        return ans;
    }
};
```

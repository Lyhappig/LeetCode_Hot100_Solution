## 两数之和

### 问题

给定一个整数数组 `nums` 和一个整数目标值 $m$，求出数组中找出**和为目标值**  $m$​​ 的数对。

提示：

- $2 \leq$  `nums.length` $\leq 10^4$
- $-10^9 \leq $ `nums[i]` $\leq 10^9$
- $-10^9 \leq $ `target` $\leq 10^9$
- **只会存在一个有效答案**

### 思路一（哈希表）

使用哈希表记录每个数的出现位置。从左到右枚举数组中的每个数 $x$，若 `target - x` 出现在哈希表，则输出数对，否则将 $x$ 所在下标加入哈希表中。

注意：对于每一个 `x`，要先查询哈希表中是否存在 `target - x`，然后将 `x` 插入到哈希表中，即可保证不会让 `x` 和自己匹配。

#### 时空复杂度

将哈希表操作的时间复杂度视为 $O(1)$，则时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```c++
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> mp;
        vector<int> ans;
        for (int i = 0; i < nums.size(); i++) {
            if (mp.count(target - nums[i])) {
                ans = {mp[target - nums[i]], i};
                break;
            }
            mp[nums[i]] = i;
        }
        return ans;
    }
};
```

### 思路二（双指针）

假设存在若干对数满足**和为 $m$**，对数的集合进行排序后：
$$
a_1, a_2, a_3, ..., a_{n - 2}, a_{n - 1}, a_{n}
$$
一定有 $a_1 + a_n = m, a_2 + a_{n-1}=m,a_3 + a_{n-2}=m,\ldots$

根据上述原理，对**原数组**排序后设置两个指向首尾的指针 $l, r$，若要找出所有指针之和为 $m$ 的数对，两个指针的移动是**单调的**：

- 若 $a_l + a_r < m$，则右移指针 $l$
- 若 $a_l + a_r > m$，则左移指针 $r$
- 若 $a_l + a_r = m$，则输出答案

#### 时空复杂度

双指针的时间复杂度为 $O(n)$，时间复杂度的上限在排序 $O(n \log n)$​

空间复杂度 $O(1)$​

#### 代码

```c++
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        int n = nums.size();
        vector<pair<int, int>> res;
        for (int i = 0; i < n; i++) {
            res.push_back({nums[i], i});
        }
        sort(res.begin(), res.end());
        int l = 0, r = n - 1;
        while (l < r) {
            int sum = res[l].first + res[r].first;
            if (sum == target) {
                break;
            }
            if (sum > target) {
                r--;
            } else {
                l++;
            }
        }
        vector<int> ans{res[l].second, res[r].second};
        return ans;
    }
};
```

### 扩展

若答案不唯一，如何求出和为 $m$ 的数对个数？

- 思路一：采用哈希表记录每种值的个数，相同的值只统计一次。

- 思路二：设置两个右指针 $r_1, r_2$ 初始指向同一位置，当左指针 $l$ 固定时，移动 $r_1$ 直到 `nums[l] + nums[r1] < m`，移动 $r_2$ 直到 `nums[l] + nums[r2] = m`，则 $r_2 - r_1$ 就是 `nums[l]` 对答案的贡献。注意到当两个相同的数之和等于 $m$ 时，**不能使用上述过程求解**，而此时恰好在计算最后一段数的贡献，直接求出这段连续相同的数的个数 $p$，对答案的贡献恰好是组合数 $C_p^2$​

参考代码如下：

```c++
long long calc(int n, int m) {
    long long ans = 1;
    for (int i = 1; i <= m; i++) {
        ans = ans * (n - i + 1) / i;
    }  
    return ans;
}

long long twoSum(vector<int>& nums, int m) {
    if (nums.size() == 1) {
        return 0;
    }
    int n = nums.size();
    sort(nums.begin(), nums.end());
    long long ans = 0;
    int l = 0, r1 = n - 1, r2 = n - 1;
    while (l <= r1) {
        while (l < r1 && nums[l] + nums[r1] >= m) {
            r1--;
        }
        while (r1 < r2 && nums[l] + nums[r2] > m) {
            r2--;
        }
        if (l == r1 && nums[l] == nums[r1] && nums[l] * 2 == m) {
            ans += calc(r2 - r1 + 1, 2); 
            break;
        }
        if (nums[l] + nums[r2] == m) {
            ans += r2 - r1;
        }
        l++;
    }
    return ans;
}
```

## 最长连续序列

### 问题

给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

提示：

- $0 \leq$ `nums.length` $\leq 10^5$
- $-10^9 \leq $ `nums[i]` $\leq 10^9$

### 思路一（哈希表）

假设将所有的整数放在数轴上，形成一个个连续的区间。上述问题等价于**随机遍历区间上的点，每个点仅会被遍历一次**，如何通过 $n$ 次遍历求出最长的区间长度。

一个简单的想法是使用**哈希表**记录下已经遍历过的数，对于每个遍历到的数 $x$，不断增加它的值检查是否存在于哈希表。但是这个过程可能一个区间会被遍历多个段，时间复杂度无法保证 $O(n)$​

巧妙的思路是**仅通过区间的左端点或者右端点来遍历该区间**，例如只有遍历到区间左端点 $l$ 时（哈希表中不存在 $l - 1$），不断增加 $l$ 直到遍历完整个区间，获得区间长度。这样每个区间只会被遍历一次。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```c++
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_map<int, bool> mp;
        for (int i = 0; i < nums.size(); i++) {
            mp[nums[i]] = 1;
        }
        int ans = 0;
        for (int i = 0; i < nums.size(); i++) {
            int x = nums[i];
            if (mp.count(x - 1)) continue;
            int res = 0;
            while (mp.count(x)) {
                x++;
                res++;
            }
            ans = max(ans, res);
        }
        return ans;
    }
};
```

### 思路二（并查集）

对于存在于数组中的所有 $x$ 和 $x+1$ 之间连一条边，问题变成求图中最大的联通块。使用记录连通块大小的并查集寻找答案，因为值域很大，所以必须通过哈希表进行离散化。一个简单但常数大的思路是使用哈希表直接进行合并操作。

#### 时空复杂度

时间复杂度 $O(n)$，但是常数略大

空间复杂度 $O(n)$

#### 代码

```c++
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        if (nums.empty()) return 0;
        unordered_map<int, int> f;
        unordered_map<int, int> size;
        for (auto &x : nums) {
            if (!f.count(x)) {
                f[x] = x;
                size[x] = 1;
            }
        }
        function<int(int)> find = [&](int x) -> int {
            return f[x] == x ? x : f[x] = find(f[x]);
        };
        int ans = 1;
        auto merge = [&](int x, int y) {
            int fx = find(x), fy = find(y);
            if (fx != fy) {
                f[fx] = fy;
                size[fy] += size[fx];
                ans = max(ans, size[fy]);
            }
        };
        for (auto &x : nums) {
            if (f.count(x + 1)) {
                merge(x, x + 1);
            }
        }
        return ans;
    }
};
```

## 字母异位词分组

### 问题

给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。

提示：

- $1 \leq$ `strs.length` $\leq 10^4$
- $0 \leq$ `strs[i].length` $\leq 100$
- `strs[i]` 仅包含小写字母

### 思路（哈希表）

区分字母异位词，有两种方式：

- 所有字符串都排序，然后按照排序后的结果哈希归类；
- 对于所有字符串都用一个长度 26 的计数数组，按照所有字符串对应计数数组归类。

#### 时空复杂度

设字符串的最长长度为 $L$，时间复杂度为 $O(n \cdot L \log L)$

空间复杂度 $O(n \cdot L)$​

#### 代码

```c++
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> mp;
        for (auto &str : strs) {
            string s = str;
            sort(s.begin(), s.end());
            mp[s].push_back(str);
        }
        vector<vector<string>> ans;
        for (auto &[key, value] : mp) {
            if (!value.empty()) {
                ans.push_back(value);
            }
        }
        return ans;
    }
};
```

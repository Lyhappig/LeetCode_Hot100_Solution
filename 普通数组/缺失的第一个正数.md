## 缺失的第一个正数

### 问题

给你一个未排序的整数数组 `nums` ，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 `O(n)` 并且只使用常数级别额外空间的解决方案。

提示：

- $1\leq$ `nums.length` $\leq 10^5$
-  $-2^{31} \leq nums[i] \leq 2^{31} - 1$

### 思路（哈希）

如果不考虑题目限制，使用哈希表记录出现过的元素，然后从 $1$ 开始遍历直到找到第一个未出现在哈希表中的数。

题目中数组大小最大为 $10^5$，因此答案最大的可能值仅为 $10^5 + 1$。考虑**使用原数组进行哈希映射**，当 $i < n$ 时，将 $i$ 映射到下标 $i - 1$ 的位置。对于 $nums[i]$，若 $0 < nums[i] \leq n$ 且对应下标位置 $i - 1$ 的数不为 $i$，则将其置换到对应下标位置；置换后还需考虑新的 $nums[i]$​​ 是否需要操作，类似**环状替换**的过程。

遍历所有位置，若存在则第一个 $nums[i] \ne i + 1$ 的位置即为答案 $i+1$；否则答案为 $n + 1$

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            while (nums[i] > 0 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                swap(nums[i], nums[nums[i] - 1]);
            }
        }
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) {
                return i + 1;
            }
        }
        return n + 1;
    }
};
```

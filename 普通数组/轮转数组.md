## 轮转数组

### 问题

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

提示：

- $1 \leq$ `nums.length` $\leq 10^5$
- $-2^{31} \leq nums[i] \leq 2^{31} - 1$
- $0 \leq k \leq 10^5$

### 思路一（使用额外的数组）

 $\forall i \in [0, n),t[(i + k) \% n] = nums[i]$

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k %= n;
        vector<int> temp(nums.size());
        for(int i = 0; i < nums.size(); i++) temp[(i + k) % n] = nums[i];
        for(int i = 0; i < nums.size(); i++) nums[i] = temp[i];
    }
};
```

### 思路二（翻转数组）

该方法基于如下的事实：当我们将数组的元素向右移动 $k$ 次后，尾部 $k \bmod n$ 个元素会移动至数组头部，其余元素向后移动 $k \bmod n$ 个位置。

该方法为数组的翻转：我们可以先将所有元素翻转，这样尾部的 $k \bmod n$ 个元素就被移至数组头部，然后我们再翻转 $[0,k \bmod n −1 ]$ 区间的元素和 $[k \bmod n, n - 1]$ 区间的元素即能得到最后的答案。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k %= n;
        if(k == 0) return;
        auto Reverse = [&](int l, int r) {
            while(l < r) {
                swap(nums[l++], nums[r--]);
            }
        };
        Reverse(0, n - 1);
        Reverse(0, k - 1);
        Reverse(k, n - 1);
    }
};
```

### 思路三（环状替换）

对于位置 $i$ 上的数，轮转之后会到达 $(i + k) \bmod n$ 的位置，再不断向后扩展，可以发现轮转的数会形成一个**环**。环上所有下标属于集合 $\{i,(i + k) \bmod n, (i + 2k) \bmod n, \ldots, (i + a \cdot k) \bmod n\}$​

令 $i = 0$，对环执行**环状替换**后再次回到起点时，假设遍历了 $a$ 个元素（即环上共有 $a$ 个元素），环覆盖了整个数组 $b$ 圈。可以得出 $a \cdot k = b \cdot n$，即 $b \cdot n$ 为 $n,k$ 的公倍数，又因为环第一次回到起点，所以 $a \cdot k = b \cdot n = \text{lcm}(n, k)$，因此 $a = \text{lcm}(n, k) / k$​

对于 $i \in [0, n)$ 的每一个位置，其实都等价于 $i = 0$ 时的位置，**从它们出发找到的环的长度也都是相同的**。环的数目等于：
$$
\frac{n}{\text{lcm}(n, k) / k} = \gcd(n, k)
$$
因此只需要从下标 $[0, \gcd(n, k))$ 下标的元素找到所有的环，即可不重不漏地覆盖所有的 $n$ 个元素，对每个环依次进行**环状相邻替换**，即可完成数组的轮转。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k %= n;
        int g = __gcd(n, k);
        for (int s = 0; s < g; s++) {
            int i = s, j = (s + k) % n;
            int pre = nums[i];
            do {
                swap(pre, nums[j]);
                i = j;
                j = (j + k) % n;
            } while (i != s);
        }
    }
};
```

## 在排序数组中查找元素的第一个和最后一个位置

### 问题

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

提示：

- $0\leq$ `nums.length` $\leq 10^5$
- $-10^9 \leq$ `nums[i]` $\leq 10^9$
- `nums` 是一个非递减数组
- $-10^9 \leq$ `target` $\leq 10^9$

### 思路（二分）

对于寻找目标值下界的函数（序列中大于等于目标值的第一个位置），在开区间 $[0,n)$ 中二分，判断区间中点 $mid$ 和目标值的关系：

- 若 $nums[mid]<target$，令 $l=mid+1$；
- 否则 $r=mid$。

当不存在下界时，$l$ 恰好取到区间边界 $n$，还需要特判 $target < nums[0]$ 的特殊情况。

对于寻找目标值的上界，只需要寻找 $target+1$ 的下界并减一。

#### 时空复杂度

时间复杂度 $O(\log n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    int lower_bound(vector<int>& nums, int target) {
        int l = 0, r = nums.size();
        while (l < r) {
            int mid = (l + r) >> 1;
            if (nums[mid] < target) {
                l = mid + 1;
            } else {
                r = mid;
            }
        }
        return l;
    }

    vector<int> searchRange(vector<int>& nums, int target) {
        vector<int> ans;
        int l = lower_bound(nums, target);
        if (l == nums.size() || nums[l] != target) {
            ans = {-1, -1};
            return ans;
        }
        int r = lower_bound(nums, target + 1);
        ans = {l, r - 1};
        return ans;
    }
};
```

### 思路二（倍增）

采用倍增代替二分，初始设置指针 $i=0$，步长 $p=1$，寻找下界的过程为：

- 若指针向后跳步长的距离后未越界且 $nums[i+p]<target$，则将指针更新为 $i=i+p$，并将步长扩大一倍 $p=p\times 2$；
- 否则将步长缩小一倍 $p=p/2$；

当 $p=0$ 时结束倍增，$nums[i+1]$ 就是题目的下界，还需要特判 $nums[0]=target$ 的情况。

寻找上界的过程类似，只需要将判断条件修改为 $nums[i+p] \leq target$。

#### 时空复杂度

时间复杂度 $O(\log n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        if (nums.size() == 0) {
            vector<int> ans{-1, -1};
            return ans;
        }
        int l = -1, r = -1, n = nums.size();
        // lower bound
        int i = 0, p = 1;
        while (p) {
            if (i + p < n && nums[i + p] < target) {
                i += p;
                p <<= 1;
            } else {
                p >>= 1;
            }
        }
        if (nums[i] == target) {
            l = i;
        } else if (i < n - 1 && nums[i + 1] == target) {
            l = i + 1;
        }
        // upper bound
        i = 0, p = 1;
        while (p) {
            if (i + p < n && nums[i + p] <= target) {
                i += p;
                p <<= 1;
            } else {
                p >>= 1;
            }
        }
        if (nums[i] == target) {
            r = i;
        }
        vector<int> ans{l, r};
        return ans;
    }
};
```

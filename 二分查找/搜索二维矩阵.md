## 搜索二维矩阵

### 问题

给你一个满足下述两条属性的 `m x n` 整数矩阵：

- 每行中的整数从左到右按非严格递增顺序排列。
- 每行的第一个整数大于前一行的最后一个整数。

给你一个整数 `target` ，如果 `target` 在矩阵中，返回 `true` ；否则，返回 `false` 。

提示：

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 100`
- $-10^4\leq$ `matrix[i][j], target` $\leq10^4$

### 思路一（排除法）

设置指针指向元素 $a[i][j]$，初始令 $i=0,j=m-1$，每次必定向着左侧和下侧其中一个方向移动：

- 若 $a[i][j]<a[i+1][j]$，则 $\forall k \in[i+1,n-1]$ 都有 $a[i][j]<a[k][j]$，该列被排除，指针向左移动。
- 若 $a[i][j-1]<a[i][j]$，则 $\forall k \in[0,j-1]$ 都有 $a[i][k]<a[i][j]$，该行被排除，指针向下移动。

重复上述过程直到找到目标元素或者移出矩阵判定为无解。

#### 时空复杂度

时间复杂度 $O(n+m)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int n = matrix.size(), m = matrix[0].size();
        int i = 0, j = m - 1;
        while (i < n && j >= 0) {
            if (matrix[i][j] == target) return true;
            else if (matrix[i][j] < target) {
                ++i;
            } else {
                --j;
            }
        }
        return false;
    }
};
```

### 思路二（二分）

根据条件二，首先对首列二分，确定 `target` 的行编号，最后对该行进行二分。为了方便考虑目标值不在矩阵中的情况，二分的目标变成找到该行/列大于 `target` 的第一个元素。一般地，对闭区间 $[1,n]$ 进行二分：

1. 如果中点 $\text{mid}$ 满足 $x < a[\text{mid}]$，那么令查找区间向左收缩，但是并不需要取中点的邻点，而是 $r = \text{mid}$
2. 否则令查找区间向右收缩，即 $l = \text{mid} + 1$

这种写法将可能作为答案的值保存在右边界：如果答案会更小，那么 $r$ 将被更新；如果答案就是 $r$，那么 $l$ 会不断向右移动直到等于 $r$。因此无论哪种情况，最终都将满足 $l=r$，返回 $l$ 或 $r$ 均是正确的。当 $l=0$ 时代表无解。

#### 时空复杂度

时间复杂度 $O(\log (n \times m))$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int n = matrix.size(), m = matrix[0].size();
        int l = 0, r = n;
        while (l < r) {
            int mid = (l + r) >> 1;
            if (target < matrix[mid][0])
                r = mid;
            else 
                l = mid + 1;
        }
        if (l == 0) return false;
        int row = l - 1;
        l = 0, r = m;
        while (l < r) {
            int mid = (l + r) >> 1;
            if (matrix[row][mid] == target) return true;
            else if(matrix[row][mid] > target) 
                r = mid;
            else 
                l = mid + 1;
        }
        return false; 
    }
};
```

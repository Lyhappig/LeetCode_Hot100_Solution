## 三数之和

### 问题

给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：**答案中不可以包含重复的三元组。

提示：

- $3 \leq$ `nums.length` $\leq 3000$
- $-10^5 \leq$ `nums[i]` $\leq 10^5$

### 思路（双指针）

考虑枚举 `nums[i]`，问题变成了如何找出所有的两元组，满足 `nums[j] + nums[k] = -nums[i]`，此时问题变成了两数之和，考虑使用两数之和的双指针解法求解，首先对所有的数进行排序。

因为答案要求不重复，因此**枚举范围是 $[i + 1, n)$​**，而且在相向双指针枚举时，对于一对满足条件的答案，需要不断移动直到找到不重复的下一对数。

#### 时空复杂度

时间复杂度 $O(n^2)$

空间复杂度 $O(1)$​

#### 代码

```java
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> ans;
        sort(nums.begin(), nums.end());
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            int target = -nums[i];
            int l = i + 1, r = n - 1;
            while (l < r) {
                if (nums[l] + nums[r] == target) {
                    vector<int> res{nums[i], nums[l], nums[r]};
                    ans.push_back(res);
                    ++l, --r;
                    while (l < r && nums[l] == nums[l - 1]) l++;
                    while (l < r && nums[r] == nums[r + 1]) r--; 
                } else if (nums[l] + nums[r] < target) {
                    l++;
                    while (l < r && nums[l] == nums[l - 1]) l++;
                } else {
                    r--;
                    while (l < r && nums[r] == nums[r + 1]) r--; 
                }
            } 
        }
        return ans;
    }
};
```

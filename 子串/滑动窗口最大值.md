## 滑动窗口最大值

### 问题

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回**滑动窗口中的最大值**。

提示：

- $1 \leq$ `nums.length` $\leq 10^5$
- $-10^4 \leq$ `nums[i]` $\leq 10^4$
- `1 <= k <= nums.length`

### 思路一（单调队列）

设置一个长度为 $k$ 的滑动窗口，从数组的最左端开始不断地向右滑动，滑动的过程为：将上一个窗口最左端的元素剔除，在最右端加入一个新的元素。

假设 $a_i$ 是窗口中最大的元素，那么窗口内 $\forall j < i, a_j \le a_i$，当窗口再向右滑动时，由于窗口中存在比 $a_j$ 更大的数且 $a_j$ 会更早的移除窗口，$a_j$ 一定不会作为新窗口的最大值。

根据上述结论，在从左向右遍历窗口时，**采用单调递减的形式维护窗口里的数**，即大小始终为 $k$ 的双端队列 $Q=[a_x , a_y , a_z , \cdots],a_x > a_y > a_z > \cdots$，设当窗口滑动到下标 $i$ 时：

- 首先检查在队列首端（最大值所处的一端）的元素，如果其下标同当前下标 $i$ 之差大于等于 $k$，代表它已经不属于这个窗口，那么直接从队列删去。

- 对于该队列中的新增元素 $a_i$，应该从队列尾端（最小值所处的一端）依次比较，满足小于等于 $a_i$ 的元素在后续滑动中不会作为新窗口的最大值，直接从队列中删去。最终 $a_i$ 将作为队列新的尾端，队列满足单调性。

- 更新下标 $i$ 处的答案为**队列首端**的元素。

维护该问题需要的数据结构是：基本数据单元是下标或者下标和值的二元组，首端只用于删去，尾端用于插入和删去的线性表。双端队列可以很好的满足要求，队列从前到后不一定是**单调递减**的，将上述单调队列模型反转，仍然可以达到相同的效果。

> 数组模拟双端队列时，因为队列长度是动态变化的，而数组的下标不能有负数，因此必须维护**从左到右单调递减**的双端队列

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(k)$​

#### 代码

```C++
struct Linear_Queue {
  int n, k, l, r;
  vector<int> a;
  vector<int> q;

  Linear_Queue() {}

  Linear_Queue(int n, int k) {
      this->n = n;
      this->k = k;
      this->l = 1;
      this->r = 0;
      a.resize(n + 1);
      q.resize(n + 1);
  }

  void pop_front(int i) {
      while (r >= l && q[l] <= i - k) {
          l++;
      }
  }

  void pop_back(int i) {
      while (r >= l && a[q[r]] <= a[i]) {
          r--;
      }
  }

  void push_back(int i) {
      pop_back(i);
      q[++r] = i;
  }

  int front() {
      return a[q[l]];
  }

  void solve(vector<int> &ans) {
      for (int i = 1; i <= n; i++) {
          pop_front(i);
          push_back(i);
          if (i >= k) {
              ans.push_back(front());
          }
      }
  }
};

class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        Linear_Queue dq(nums.size(), k);
        for(int i = 0; i < nums.size(); i++) {
            dq.a[i + 1] = nums[i];
        }
        vector<int> ans;
        dq.solve(ans);
        return ans;
    }
};
```

### 思路二（ST 表）

使用**ST表预处理**以 $i$ 为起点长度为 $2^j$ 的最大值，对于每个长度为 $k$ 的窗口 $O(1)$ 查询即可。

#### 时空复杂度

时间复杂度 $O(n \log n)$

空间复杂度 $O(n \log n)$​

#### 代码

```C++
class SparseTable {
private:
    int n;
    vector<vector<int>> d;
    vector<int> _log2;
public:
    SparseTable() {}

    SparseTable(int n) {
        this->n = n;
        _log2.resize(n + 1);
        _log2[1] = 0;
        for (int i = 2; i <= n; i++) {
            _log2[i] = _log2[i / 2] + 1;
        }
        d.resize(n + 1);
        for (int i = 1; i <= n; i++) {
            d[i].resize(_log2[n] + 1);
        }
    }

    void init(vector<int> &nums) {
        for (int i = 1; i <= n; i++) d[i][0] = nums[i - 1];
        for (int j = 1; (1 << j) <= n; j++) {
            for (int i = 1; i + (1 << (j - 1)) <= n; i++) {
                d[i][j] = max(d[i][j - 1], d[i + (1 << (j - 1))][j - 1]);
            } 
        }
    }

    int query(int l, int r) {
        int k = _log2[r - l + 1];
        return max(d[l][k], d[r - (1 << k) + 1][k]);
    }
};

class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        SparseTable *st = new SparseTable(nums.size());
        st->init(nums);
        vector<int> ans(nums.size() - k + 1);
        for (int i = 0; i + k - 1 < nums.size(); i++) {
            ans[i] = st->query(i + 1, i + k);
        }
        delete st;
        return ans;
    }
};
```

## 最小覆盖子串

### 问题

给你一个字符串 `s` 、一个字符串 `t` 。返回 `s` 中涵盖 `t` 所有字符的最小子串。如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串 `""` 。

**注意：**

- 对于 `t` 中重复字符，我们寻找的子字符串中该字符数量必须不少于 `t` 中该字符数量。
- 如果 `s` 中存在这样的子串，我们保证它是唯一的答案。

提示：

- `m == s.length`
- `n == t.length`
- $1 \leq n, m \leq 10^5$
- `s` 和 `t` 由英文字母组成

### 思路（双指针）

设 $l=f(r)$ 代表字符串 `s` 以 $r$ 为终点，恰好覆盖 `t` 所有字符最小子串的左（闭）区间。当 $r \rightarrow r+1$ 时，$f(r) \leq f(r+1)$，双指针具备单调性，因此可以通过线性时间复杂度的双指针算法求解。

如何判断一个区间是否包含了 `t` 的所有子串，一个简便的做法是对字符串 `s` 和字符串 `t` 分别维护一个计数数组，每次移动后判断是否符合条件，这样做的时间复杂度是 $O(\sum \cdot n)$，其中 $\sum = 52$

因为移动时只会导致一个计数位置变化 1，可以采用类似《**找到字符串中所有字母异位词**》题目的做法：初始遍历 `t` 数组，令计数数组中对应字符位为负数，变量 `differ` 表示有多少个位置为负数；当字符串 `s` 的指针 `l,r` 移动时，根据计数位置的增减处理 `differ` 的变化：

- 若计数数组中，关于 `t` 的每个位置都大于等于 0，则此时 `differ = 0`，代表**当前子串覆盖了子串 `t`**；
- 若计数数组中，存在关于 `t` 的每个位置小于 0，则此时 `differ > 0`，代表**当前子串未覆盖子串 `t`**；

> 注意，`Z` 和 `a` 中间存在若干非字母字符，需要设置**计数数组的长度不小于 `int('z' - 'A') = 57`**

#### 时空复杂度

时间复杂度 $O(n + m)$

空间复杂度 $O(\sum)$​

#### 代码

```C++
class Solution {
public:
    string minWindow(string s, string t) {
        string empty;
        int n = s.size(), m = t.size();
        if(n < m) return empty;
        vector<int> cnt(60, 0);
        for (int i = 0; i < m; i++) {
            cnt[t[i] - 'A']--;
        }
        int differ = 0;
        for (int i = 0; i < 60; i++) {
            if (cnt[i] < 0) {
                differ++;
            }
        }
        int start = -1, len = 0x3f3f3f3f;
        for (int l = 0, r = 0; r < s.size(); r++) {
            if (cnt[s[r] - 'A'] == -1) differ--;
            ++cnt[s[r] - 'A'];
            while (l <= r && differ == 0) {
                if (cnt[s[l] - 'A'] == 0) differ++;
                --cnt[s[l] - 'A'];
                if (r - l + 1 < len) {
                    start = l;
                    len = r - l + 1;
                }
                l++;
            }
        }
        return start == -1 ? empty : s.substr(start, len);
    }
};
```

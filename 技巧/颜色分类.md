## 颜色分类

### 问题

给定一个包含红色、白色和蓝色、共 `n` 个元素的数组 `nums` ，原地对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。

我们使用整数 `0`、 `1` 和 `2` 分别表示红色、白色和蓝色。

必须在不使用库内置的 sort 函数的情况下解决这个问题。

提示：

- `n == nums.length`
- `1 <= n <= 300`
- `nums[i]` 为 `0`、`1` 或 `2`

### 思路一（双指针）

对数组进行两次遍历。第一次遍历将数组中所有的 0 交换到数组的头部。第二次遍历将数组中所有的 1 交换到头部的 0 之后。此时，所有的 2 都出现在数组的尾部，这样我们就完成了排序。设置指针 $p$ 表示一段连续 `0` 或 `1` 的下一个位置，初始 $p=0$，代表一段空元素的下一个位置。

- 在第一次遍历中，从指针 $p$ 开始，从左向右遍历整个数组，如果找到了 0，那么就将 0 与指针 $p$ 的元素进行交换，并将指针 $p$ 向后扩充一个位置。在遍历结束之后，所有的 0 都被交换到数组的头部，即下标范围 $[0,p)$。
- 在第二次遍历中，从指针 $p$ 继续，从左向右遍历整个数组，如果找到了 1，那么就将 1 与指针 $p$ 的元素进行交换，并将指针 $p$ 向后扩充一个位置。在遍历结束之后，所有的 1 都被交换到一段连续范围，并且都在 0 之后，此时 2 只出现在数组尾部的一段连续范围，因此排序完成。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```c++
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int n = nums.size();
        int p = 0;
        for (int i = 0; i < n; ++i) {
            if (nums[i] == 0) {
                swap(nums[i], nums[p]);
                ++p;
            }
        }
        for (int i = p; i < n; ++i) {
            if (nums[i] == 1) {
                swap(nums[i], nums[p]);
                ++p;
            }
        }
    }
};
```

### 思路二（三指针）

设指针 $i$ 代表一段连续 0 的尾部元素，初始为越界下标 $-1$；设指针 $k$ 代表一段连续 2 的首部元素（从右向左方向），初始为越界下标 $n$；再设置指针 $j$ 从前到后枚举数组中所有元素：

- 若 $nums[j] < 1$，则交换 $nums[i+1],nums[j]$，并分别将两个指针 $i,j$ 向右移动一位；
- 若 $nums[j] > 1$，则交换 $nums[k-1],nums[j]$，并将指针 $j$ 向右移动一位，将指针 $k$ 向左移动一位；
- 否则只需将指针 $j$ 向右移动一位，代表移动到一段连续的 1 的下一个待判断位置。

当 $j = k$ 时结束遍历，完成颜色分类。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int i = -1, j = 0, k = nums.size();
        while (j < k) {
            if (nums[j] < 1) {
                swap(nums[++i], nums[j++]);
            } else if (nums[j] > 1) {
                swap(nums[j], nums[--k]);
            } else {
                j++;
            }
        }
    }
};
```

## 多数元素

### 问题

给定一个大小为 `n` 的数组 `nums` ，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

提示：

- `n == nums.length`
- $1\leq$ `n` $\leq 5 \times 10^4$
- $-10^9\leq $ `nums[i]` $\leq 10^9$

### 思路一（快速选择算法）

类似《**数组中的第K个最大元素**》，使用快速选择算法。在快速排序中每次选择的分界值，其下标正好对应排序后的位置，可以通过改进快速排序算法解决问题。在快速排序的过程当中，我们会对子数组进行划分，如果划分后基准数 $\text{pivot}$ 所处位置 $q$ 正好是第 $k$ 小，则直接返回；如果 $q$​ 比目标下标小，就递归右子区间，否则递归左子区间。这样就可以把原来递归两个区间变成只递归一个区间，提高了时间效率。

在随机选择基准数的情况下，该算法期望时间复杂度为：
$$
O(\frac{n}{2} + \frac{n}{4} + \frac{n}{8} + \ldots) \approx O(n)
$$
在快速排序的多种实现中，三向切分快排表现最佳。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(\log n)$​

#### 代码

```C++
class Solution {
public:
    int quick_sort(vector<int>& nums, int l, int r, int kth) {
        if (l == r) return nums[l];
        int pos = rand() % (r - l + 1) + l;
        swap(nums[l], nums[pos]);
        int i = l, k = l + 1, j = r;
        int pivot = nums[l];
        while (k <= j) {
            if (nums[k] < pivot) {
                swap(nums[k], nums[i]);
                i++;
                k++;
            } else if (nums[k] > pivot) {
                swap(nums[k], nums[j]);
                j--;
            } else {
                k++;
            }
        }
        if (i <= kth && kth <= j) return nums[i];
        if (kth < i) return quick_sort(nums, l, i - 1, kth);
        return quick_sort(nums, j + 1, r, kth);
    }

    int majorityElement(vector<int>& nums) {
        int n = nums.size();
        return quick_sort(nums, 0, n - 1, n / 2);
    }
};
```

### 思路二（随机化）

因为超过 $\lfloor\frac{n}{2}\rfloor$ 的数组下标被众数占据了，这样我们随机挑选一个下标对应的元素并验证，有很大的概率能找到众数。随机挑选一个下标，枚举序列所有元素检查它是否为众数，如果是就返回，否则继续随机挑选。

由于众数占据 **超过** 数组一半的位置，期望的随机次数会小于众数占据数组恰好一半的情况。因此随机的期望次数：
$$
\lim_{n\rightarrow \infty} \sum_{i=1}^n i\cdot \frac{1}{2^i} \approx 2
$$

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    bool work(vector<int>& nums, int target) {
        int cnt = 0;
        for (int x : nums) {
            if (x == target) {
                ++cnt;
            }
        }
        return cnt > nums.size() / 2;
    }

    int majorityElement(vector<int>& nums) {
        srand(time(0));
        while (true) {
            int target = nums[rand() % nums.size()];
            if (work(nums, target)) {
                return target;
            }
        }
    }
};
```

### 思路三（Boyer-Moore 投票算法）

维护一个候选众数 candidate 和它出现的次数 `count`。初始时 `candidate` 可以为任意值，`count` 为 0；遍历数组中的所有元素，对于每个元素 $x$，在判断 $x$ 之前，如果 `count` 的值为 0，则先将 $x$ 的值赋予 `candidate`，随后判断 $x$：

- 如果 $x$ 与 `candidate` 相等，那么计数器 `count` 的值增加 1；
- 如果 $x$ 与 `candidate` 不等，那么计数器 `count` 的值减少 1。

在遍历完成后，`candidate` 即为整个数组的众数。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int candidate = -1;
        int count = 0;
        for (int x : nums) {
            if (count == 0) {
                candidate = x;
            }
            if (x == candidate) {
                ++count;
            } else {
                --count;
            }
        }
        return candidate;
    }
};
```

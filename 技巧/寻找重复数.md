## 寻找重复数

### 问题

给定一个包含 `n + 1` 个整数的数组 `nums` ，其数字都在 `[1, n]` 范围内（包括 `1` 和 `n`），可知至少存在一个重复的整数。

假设 `nums` 只有 **一个重复的整数** ，返回 **这个重复的数** 。

你设计的解决方案必须 **不修改** 数组 `nums` 且只用常量级 `O(1)` 的额外空间。

提示：

- $1\leq n \leq 10^5$
- `nums.length == n + 1`
- `1 <= nums[i] <= n`
- `nums` 中 **只有一个整数** 出现 **两次或多次** ，其余整数均只出现 **一次**

### 思路一（二分）

对区间 $[1, n]$ 二分，设左半区间为 $[l,mid]$，遍历整个数组，判断在该区间内的元素个数 $x$：

- 若 $x > mid - l + 1$，则重复数的数值必定出现在 $[l,mid]$ 范围内，令 $r=mid$；
- 否则重复数的数值必定出现在 $[mid+1,r]$ 范围内，令 $l=mid+1$。

当 $l=r$ 时，恰好是重复数对应的值。

#### 时空复杂度

时间复杂度 $O(n \log n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        auto hasRepeat = [&](int left, int right) -> bool {
            int count = 0;
            for (auto &x : nums) {
                if (left <= x && x <= right) {
                    count++;
                }
            }
            return count > right - left + 1;
        };
        int l = 1, r = nums.size() - 1, mid;
        while (l < r) {
            mid = (l + r) >> 1;
            if (hasRepeat(l, mid)) {
                r = mid;
            } else {
                l = mid + 1;
            }
        }
        return l;
    }
};
```

### 思路二（环状替换）

**该方法修改了原数组！**

采用类似《**确实的第一个正数**》的方法，使用原数组进行哈希映射。初始令 $i=0$，不断比较 $nums[nums[i]]$ 和 $nums[i]$ 的关系：

- 若不相同则交换二者；
- 否则退出，找到了重复数。

不断交换的过程类似环状替换的过程。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        int i = 0;
        while (nums[nums[i]] != nums[i]) {
            swap(nums[i], nums[nums[i]]);
        }
        return nums[i];
    }
};
```

### 思路三（快慢指针）

将数组的下标和值做一个映射，例如 `[1, 3, 4, 2, 2]` 将表示为：
$$
0\rightarrow 1\\
1\rightarrow 3\\
2\rightarrow 4\\
3\rightarrow 2\\
4\rightarrow 2\\
$$
再例如 `[3, 3, 3, 3, 3]` 将表示为：
$$
0\rightarrow 3\\
1\rightarrow 3\\
2\rightarrow 3\\
3\rightarrow 3\\
4\rightarrow 3\\
$$
具体来说：

- 如果数组中没有重复的数，从下标 0 出发，根据映射进行遍历将产生一个无环的单链表。
- 如果数组中有重复的数，那么从下标 0 出发根据映射的遍历一定存在环，环的起点即为重复的数。

采用《**环形链表II**》的思路，可以求出环的起点，即为重复的数。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        int i = 0, j = 0;
        do {
            i = nums[i];
            j = nums[nums[j]];
        } while (i != j);
        i = 0;
        while (i != j) {
            i = nums[i];
            j = nums[j];
        }
        return i;
    }
};
```

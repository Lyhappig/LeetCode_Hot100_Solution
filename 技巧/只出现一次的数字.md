## 只出现一次的数字

### 问题

给你一个 **非空** 整数数组 `nums` ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

提示：

- $1\leq$ `nums.length` $\leq 3\times 10^4$
- $-3\times 10^4 \leq$ `nums[i]`  $\leq 3\times 10^4$
- 除了某个元素只出现一次以外，其余每个元素均出现两次。

### 思路（位运算）

根据异或运算 $x\oplus x=0, y \oplus 0=y$ 的性质，只需要将数组每个元素异或一次，最终得到的元素即为出现一次的元素。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int sum = 0;
        for (auto x : nums) {
            sum ^= x;
        }
        return sum;
    }
};
```

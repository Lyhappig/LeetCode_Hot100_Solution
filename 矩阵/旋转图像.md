## 旋转图像

### 问题

给定一个 *n* × *n* 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在**原地**旋转图像，这意 味着你需要直接修改输入的二维矩阵。**请不要**使用另一个矩阵来旋转图像。

提示：

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

### 思路一（逐层旋转）

<img src="https://pic.leetcode-cn.com/1638557961-AVzCQb-ccw-01-07.001.png" alt="ccw-01-07.001.png" style="zoom: 33%;" />

矩阵顺时针旋转 90º 后，可找到以下规律：

- 第 $i$ 行所有元素旋转到第 $n - 1 - i$ 列；
- 第 $j$ 列所有元素旋转到第 $i$​ 行；

因此对于矩阵任意位置 $(i, j)$ 上的元素，其翻转后来到位置 $(j, n - 1 - i)$

以位于矩阵四个角点的元素为例，设矩阵左上角元素 $A$、右上角元素 $B$、右下角元素 $C$、左下角元素 $D$。矩阵旋转 90º 后，相当于依次先后执行 $D \rightarrow A, C \rightarrow D , B \rightarrow C , A \rightarrow B$ 修改元素，如下图所示：

<img src="https://pic.leetcode-cn.com/1638557961-hYpOoH-ccw-01-07.003.png" alt="ccw-01-07.003.png" style="zoom:33%;" />

将矩阵划分为 $n/2$ 个**空心方阵**，由外到内逐层旋转。$m \times m$ 的空心方阵包含 $4 \times (m - 1)$ 个元素，每次选择 $4$ 个元素进行旋转，根据[189. 轮转数组](https://leetcode.cn/problems/rotate-array/)的思路，共需要执行 $\gcd(4 \times (m - 1), 4) = m - 1$ 次旋转。对于一个四元组，从任意一个起点采用上述图示旋转思路即可。

#### 时空复杂度

时间复杂度 $O(n \times n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        int i = 0, c = 0, m = n - 1;
        while (i < n / 2) {
            for (int j = c; j < m + c; j++) {
                int tmp = matrix[i][j];
                matrix[i][j] = matrix[n - 1 - j][i];
                matrix[n - 1 - j][i] = matrix[n - 1 - i][n - 1 - j];
                matrix[n - 1 - i][n - 1 - j] = matrix[j][n - 1 - i];
                matrix[j][n - 1 - i] = tmp;
            }
            i++, c++;
            m -= 2;
        }
    }
};
```

### 思路二（矩阵翻转）

矩阵翻转有两种做法：

- 将矩阵首先按照水平对称线翻转，然后再按照主对角线翻转

- 将矩阵首先按照主对角线翻转，然后再按照竖直对称线翻转

以第一种做法为例，对于水平轴翻转而言，我们只需要枚举矩阵上半部分的元素，和下半部分的元素进行交换，即
$$
matrix[r][c] \rightarrow matrix[n - r - 1][c]
$$
对于主对角线翻转而言，我们只需要枚举对角线左侧的元素，和右侧的元素进行交换，即
$$
matrix[r][c] \rightarrow matrix[c][r]
$$
将它们联立即可得到：
$$
matrix[r][c] \rightarrow matrix[c][n - r - 1]
$$

#### 时空复杂度

时间复杂度 $O(n \times n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    void rotate(vector<vector<int>> &matrix) {
        int n = matrix.size();
        // 水平翻转
        for (int i = 0; i < n / 2; ++i) {
            for (int j = 0; j < n; ++j) {
                swap(matrix[i][j], matrix[n - i - 1][j]);
            }
        }
        // 主对角线翻转
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < i; ++j) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }
    }
};
```

## 螺旋矩阵

### 问题

给你一个 `m` 行 `n` 列的矩阵 `matrix` ，请按照 **顺时针螺旋顺序** ，返回矩阵中的所有元素。

提示：

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 10`
- `-100 <= matrix[i][j] <= 100`

### 思路一（模拟）

考虑假设一个对象在矩阵上行走，越界和走过的地方都会变成墙壁。行走的方向为**右下左上右下左上......**，走过的次数恰好为元素的个数 $n\times m$，当遇到墙壁时一定会按照下一个方向修正，模拟该过程即可。

#### 时空复杂度

时间复杂度 $O(n \times m)$

空间复杂度 $O(n \times m)$

#### 代码

```C++
const int dx[] = {0, 1, 0, -1};
const int dy[] = {1, 0, -1, 0};

class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        int n = matrix.size();
        int m = matrix[0].size();
        auto check = [&](int r, int c) -> bool {
            return r >= 0 && r < n && c >= 0 && c < m;
        };
        int i = 0, j = 0, k = 0, cnt = n * m;
        vector<vector<bool>> vis(n, vector<bool>(m, 0));
        vector<int> ans;
        while (cnt > 0) {
            vis[i][j] = true;
            ans.push_back(matrix[i][j]);
            if (!check(i + dx[k], j + dy[k]) || vis[i + dx[k]][j + dy[k]]) {
                k = (k + 1) % 4;
            }
            cnt--;
            i += dx[k];
            j += dy[k];
        }
        return ans;
    }
};
```

### 思路二（找规律）

可以将矩阵看成若干层，首先输出最外层的元素，其次输出次外层的元素，直到输出最内层的元素。定义四个变量 `left, right, top, bottom` 分别表示**列的左右边界、行的上下边界**，每遍历完一层后，行列表示范围收缩 $2$，即  `++left, --right, ++top, --bottom` 

每层的遍历顺序如下：

1. 从左到右遍历上侧元素，依次为 `(top, left)` 到 `(top, right)`；
2. 从上到下遍历右侧元素，依次为 `(top + 1, right)` 到 `(bottom, right)`；
3. 如果 `left < right` 且 `top < bottom`，则从右到左遍历下侧元素，依次为 `(bottom, right − 1)` 到 `(bottom, left + 1)`，以及从下到上遍历左侧元素，依次为 `(bottom, left)` 到 `(top + 1, left)`。

#### 时空复杂度

时间复杂度 $O(n \times m)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        int n = matrix.size();
        int m = matrix[0].size();
        vector<int> ans;
        int left = 0, right = m - 1;
        int top = 0, bottom = n - 1;

        while (left <= right && top <= bottom) {
            for (int j = left; j <= right; j++) {
                ans.push_back(matrix[top][j]);
            }
            for (int i = top + 1; i <= bottom; i++) {
                ans.push_back(matrix[i][right]);
            }
            if (left < right && top < bottom) {
                for (int j = right - 1; j >= left; j--) {
                    ans.push_back(matrix[bottom][j]);
                }
                for (int i = bottom - 1; i > top; i--) {
                    ans.push_back(matrix[i][left]);
                }
            }
            ++left, ++top;
            --right, --bottom;
        }
        return ans;
    }
};
```

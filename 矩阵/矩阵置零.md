## 矩阵置零

### 问题

给定一个 $m \times n$ 的矩阵，如果一个元素为 **0** ，则将其所在行和列的所有元素都设为 **0** 。请使用**原地算法**。

提示：

- `m == matrix.length`
- `n == matrix[0].length`
- `1 <= m, n <= 200`
- $-2^{31} \leq $ `matrix[i][j]` $\leq 2^{31} -1$

### 思路一（$O(m+n)$​ 空间）

使用长度为 $m$ 的数组标记某**行**是否出现零，再使用长度为 $n$ 的数组标记某**列**是否出现，最后遍历一次数组，根据位置 $(i, j)$ 找到第 $i$ 行或者第 $j$​ 列的标记数组是否被打上标记。

#### 时空复杂度

时间复杂度 $O(m \times n)$

空间复杂度 $O(m + n)$​

#### 代码

```C++
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();
        vector<bool> row(m, false);
        vector<bool> col(n, false);
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (matrix[i][j] == 0) {
                    row[i] = col[j] = true;
                }
            }
        }
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (row[i] || col[j]) {
                    matrix[i][j] = 0;
                }
            }
        }
    }
};
```

### 思路二（$O(1)$ 空间）

当 $nums[r, c] = 0$ 时，最终矩阵的第 $r$ 行和第 $c$ 列一定全为零，这是已知的信息。那么我们就可以**将第 $r$ 行和第 $c$ 列的空间作为第一种做法的标志数组，即行标志数组为 $matrix[\cdot][c]$，列标志数组为 $matrix[r][\cdot]$**，从而实现常数级别的复杂度。但是要注意，在根据行和列的标志数组判断某个位置 $(i, j)$ 是否需要置为零时，如果位置 $(i,j)$ 恰好在两个标志数组所处的十字中则需要跳过，因为**可能会打乱标志数组**。这些位置最后再单独置为零。

#### 时空复杂度

时间复杂度 $O(m \times n)$

空间复杂度 $O(1)$​

#### 代码

```C++
class Solution {
public:
    void findZero(vector<vector<int>>& matrix, int& row, int& col) {
        int m = matrix.size();
        int n = matrix[0].size();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (matrix[i][j] == 0) {
                    row = i;
                    col = j;
                    return;
                }
            }
        }
    }

    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();
        int row = -1, col = -1;
        findZero(matrix, row, col);
        if (row == -1) return;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[row][j] = matrix[i][col] = 0;
                }
            }
        }
        for (int i = 0; i < m; i++) {
            if (i == row) continue;
            for (int j = 0; j < n; j++) {
                if (j == col) continue;
                if (!matrix[row][j] || !matrix[i][col]) {
                    matrix[i][j] = 0;
                }
            }
        }
        for (int i = 0; i < m; i++) matrix[i][col] = 0;
        for (int j = 0; j < n; j++) matrix[row][j] = 0;
    }
};
```

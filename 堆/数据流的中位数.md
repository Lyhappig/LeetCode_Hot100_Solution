## 数据流的中位数

### 问题

**中位数**是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

- 例如 `arr = [2,3,4]` 的中位数是 `3` 。
- 例如 `arr = [2,3]` 的中位数是 `(2 + 3) / 2 = 2.5` 。

实现 MedianFinder 类:

- `MedianFinder() `初始化 `MedianFinder` 对象。
- `void addNum(int num)` 将数据流中的整数 `num` 添加到数据结构中。
- `double findMedian()` 返回到目前为止所有元素的中位数。与实际答案相差 `10-5` 以内的答案将被接受。

提示：

- $-10^5\leq$ `num` $\leq10^5$
- 在调用 `findMedian` 之前，数据结构中至少有一个元素
- 最多 $5\times10^4$ 次调用 `addNum` 和 `findMedian`

### 思路一（对顶堆）

为了动态维护中位数，建立两个二叉堆：一个小根堆、一个大根堆。在依次读入这个整数序列的过程中，设当前序列长度为 $n$，始终保持：

1. 序列中从小到大排名为 $1\sim \frac{n}{2}$ 的整数存储在大根堆中；

2. 序列中从小到大排名为 $\frac{n}{2}+1\sim n$ 的整数存储在小根堆中。

任何时候，如果某一个堆中元素个数过多，打破了这个性质，就取出该堆的堆顶插入另一个堆。任意时刻，序列的中位数就是小根堆的堆顶。

每次读入 $x$ 后，若 $x$ 比中位数小，则插入大根堆，否则插入小根堆，在插入后调整使得两个堆满足上述性质即可。

#### 时空复杂度

时间复杂度 $O(n\log n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class MedianFinder {
public:
    priority_queue<int> left;
    priority_queue<int, vector<int>, greater<int>> right;

    MedianFinder() {
        while (!left.empty()) left.pop();
        while (!right.empty()) right.pop();
    }
    
    void addNum(int num) {
        if (left.empty()) {
            left.push(num);
            return;
        }
        if (left.size() == right.size()) {
            if (num > right.top()) {
                left.push(right.top());
                right.pop();
                right.push(num);
            } else {
                left.push(num);
            }
        } else {
            if (num < left.top()) {
                right.push(left.top());
                left.pop();
                left.push(num);
            } else {
                right.push(num);
            }
        }
    }
    
    double findMedian() {
        return left.size() > right.size() ? left.top() : 1.0 * (left.top() + right.top()) / 2;
    }
};
```

### 思路二（有序集合+双指针）

使用有序集合维护序列，使用双指针 $l,r$ 指向有序集合中的中位数元素。当累计添加元素的数量为奇数时，双指针指向同一个元素。当累计添加元素的数量为偶数时，双指针分别指向构成中位数的两个数。

当添加元素 $x$ 到集合中时：

- 初始有序集合为空时，左右指针均指向 $x$ 所在的位置。
- 有序集合为中元素为奇数时，$l$ 和 $r$ 同时指向中位数。如果 $x$ 大于等于中位数，那么只要让 $l$ 左移，否则让 $r$ 右移。
- 有序集合为中元素为偶数时，$l$ 和 $r$ 分别指向构成中位数的两个数：
  - 当 $x$ 成为新的唯一的中位数，令 $l$ 右移，$r$ 左移，这样它们即可指向 $x$ 所在的位置；
  - 当 $x$ 大于等于 $r$，那么让 $l$ 右移即可；
  - 当 $x$ 小于 $r$ 指向的值，令 $r$ 左移，注意到如果 $x$ 恰等于 $l$ 指向的值，那么 $x$ 将被插入到 $l$ 右侧，使得 $l$ 和 $r$ 间距增大，所以还需要额外让 $l$ 指向移动后的 $r$。

#### 时空复杂度

时间复杂度 $O(n \log n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class MedianFinder {
    multiset<int> nums;
    multiset<int>::iterator left, right;

public:
    MedianFinder() : left(nums.end()), right(nums.end()) {}

    void addNum(int x) {
        int n = nums.size();
        nums.insert(x);
        if (!n) {
            left = right = nums.begin();
        } else if (n & 1) {
            if (x < *left) {
                left--;
            } else {
                right++;
            }
        } else {
            if (x > *left && x < *right) {
                left++;
                right--;
            } else if (x >= *right) {
                left++;
            } else {
                right--;
                left = right;
            }
        }
    }

    double findMedian() {
        return (*left + *right) / 2.0;
    }
};
```

### 思路三（链表+哈希）

**由于本题需要输入过程中及时获取中位数，所以该离线做法并不适合本题，面试手撕非在线测评环境时适用。**

适用题目：[https://www.acwing.com/problem/content/description/108/](https://www.acwing.com/problem/content/description/108/)

先把整个序列读入进来，排序之后构成一个双向链表，此时可以知道整个序列的中位数 $m$。随后倒序考虑本题中的读入过程，也就是把整数从链表中一个个删去。为了删除一个整数，我们需要找到该整数在链表中对应的节点，使用哈希表记录这些指针。

每次删去一个节点 $x$ 后，要么中位数不变，要么新的中位数与原来中位数节点 $m$ 的位置相邻，通过 $x$ 和 $m$ 的大小关系以及链表中元素个数分情况讨论：

- 若删除的节点恰好是中位数所在节点：
  - 若链表长度是奇数，则中位数 $m$ 左移；
  - 若链表长度是偶数，则中位数 $m$ 右移。
- 若删除中位数 $m$ 右侧节点且链表长度是奇数，则中位数右移；
- 若删除中位数 $m$ 左侧节点且链表长度是偶数，则中位数左移。

#### 时空复杂度

时间复杂度 $O(n \log n)$

空间复杂度 $O(n)$​

#### 代码

```C++
#include <bits/stdc++.h>

using namespace std;
typedef long long ll;
const int maxn = 2e5 + 10;

struct ListNode {
    int val;
    ListNode *pre;
    ListNode *nxt;

    ListNode(int value) : val(value), pre(nullptr), nxt(nullptr) {}
};

int n;
pair<int, int> a[maxn];

vector<int> solve() {
    sort(a + 1, a + n + 1);
    unordered_map<int, ListNode*> mp;
    ListNode *head = new ListNode(0);
    ListNode *mid;
    for (int i = 1; i <= n; ++i) {
        ListNode *now = new ListNode(a[i].first);
        mp[a[i].second] = now;
        head->nxt = now;
        now->pre = head;
        head = head->nxt;
        if (i == (n + 1) / 2) {
            mid = now;
        }
    }
    ListNode *tail = new ListNode(0);
    tail->pre = head;
    head->nxt = tail;
    vector<int> ans;
    for (int i = n; i >= 1; --i) {
        // 获取中位数
        if (i & 1) {
            ans.push_back(mid->val);
        }
        // 删除输入的第 i 个元素
        ListNode *now = mp[i];
        if (now == mid) {
            if (i % 2 == 1) {
                mid = mid->pre;
            } else {
                mid = mid->nxt;
            }
        } else if (now->val >= mid->val) {
            if (i % 2 == 1) mid = mid->pre;
        } else {
            if (i % 2 == 0) mid = mid->nxt;
        }
        now->pre->nxt = now->nxt;
        now->nxt->pre = now->pre;
        delete now;
    }
    return ans;
}

int main() {
    int T, kase;
    cin >> T;
    while (T--) {
        cin >> kase >> n;
        for (int i = 1; i <= n; i++) {
            cin >> a[i].first;
            a[i].second = i;
        }
        vector<int> ans = solve();
        reverse(ans.begin(), ans.end());
        auto m = ans.size();
        cout << kase << " " << m;
        for (int i = 0; i < m; i++) {
            if (i % 10 == 0) cout << "\n";
            cout << ans[i] << " ";
        }
        cout << "\n";
    }
    return 0;
}
```

## 每日温度

### 问题

给定一个整数数组 `temperatures` ，表示每天的温度，返回一个数组 `answer` ，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

提示：

- $1\leq$ `temperatures.length` $\leq10^5$
- `30 <= temperatures[i] <= 100`

### 思路（单调栈）

问题可以抽象为：给出一个长度为 $n$ 的数组 $a$，求出每个元素的**后缀**中第一个**大于**它的元素的位置。

以样例 `1 4 3 5 5 2 3 6` 为例：

- 从右到左进行分析。遍历到倒数第四个元素时，对于前缀中小于 5 的元素，因为 5 的存在，2,3 一定不会是它们的下一个更大元素，因此直接删去；遍历到倒数第五个元素时，右侧出现的 5 也不会是它的下一个更大元素，即对于相同元素，只需要保留最左边的那个。以此类推，从右到左遍历依次需要维护的集合分别是 `6`，`3 6`，`2 3 6`，`5 6`，`5 6`，`3 5 6`，`4 5 6`，`1 4 5 6`。对于每个元素，从左到右逐步淘汰集合中小于等于它的元素，直到遇到下一个更大的元素。该集合满足元素**后进先出**，自顶向下单调递增。

- 从左到右进行分析。遍历到第二个元素时，找到了 1 的下一个更大元素 4，那么 1 可以删去，将 4 加入集合；遍历到第三个元素时，没有找到集合中的下一个更大元素，将 3 加入集合；遍历到第四个元素时，5 是 4,3 的下一个更大元素，那么 4,3 都可以删去，将 5 加入集合。以此类推，从左到右依次需要维护的集合分别是 `1`，`4`，`4 3`，`5`，`5 5`，`5 5 2`，`5 5 3`，`6`。对于每个元素，从右到左逐步淘汰集合中小于它的元素，直到遇到下一个更大的元素。该集合满足元素**后进先出**，自顶向下单调不减。

从右到左维护时，栈中的元素是可能的下一个更大元素；从左到右维护时，栈中的元素是还没有找到下一个更大的元素。

维护上述问题需要的数据结构是：基本数据单元是下标或者下标和值的二元组，元素后进先出的线性表，可以用栈来维护，又因为栈是单调的，因此称为单调栈。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        vector<int> stk;
        vector<int> ans(n, 0);
        for (int i = 0; i < n; i++) {
            while (!stk.empty() && temperatures[i] > temperatures[stk.back()]) {
                ans[stk.back()] = i - stk.back();
                stk.pop_back();
            }
            stk.push_back(i);
        }
        return ans;
    }
};
```

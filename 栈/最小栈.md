## 最小栈

### 问题

设计一个支持 `push` ，`pop` ，`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类：

- `MinStack()` 初始化堆栈对象。
- `void push(int val)` 将元素val推入堆栈。
- `void pop()` 删除堆栈顶部的元素。
- `int top()` 获取堆栈顶部的元素。
- `int getMin()` 获取堆栈中的最小元素。

提示：

- $-2^{31}\leq$ `val` $\leq2^{31}-1$
- `pop`、`top` 和 `getMin` 操作总是在 **非空栈** 上调用
- `push`, `pop`, `top`, and `getMin`最多被调用 $3\times10^4$ 次

### 思路（栈）

使用一个辅助栈，与元素栈同步插入与删除，用于存储与每个元素对应的最小值：

- 当一个元素要入栈时，我们取当前辅助栈的栈顶存储的最小值，与当前元素比较得出最小值，将这个最小值插入辅助栈中；

- 当一个元素要出栈时，我们把辅助栈的栈顶元素也一并弹出；
- 在任意一个时刻，栈内元素的最小值就存储在辅助栈的栈顶元素中。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class MinStack {
public:
    vector<int> stk;
    vector<int> minStk;

    MinStack() {
        stk.clear();
        minStk.clear();
    }
    
    void push(int val) {
        stk.push_back(val);
        if (minStk.size() > 0) {
            minStk.push_back(min(minStk.back(), val));
        } else {
            minStk.push_back(val);
        }
    }
    
    void pop() {
        stk.pop_back();
        minStk.pop_back();
    }
    
    int top() {
        return stk.back();
    }
    
    int getMin() {
        return minStk.back();
    }
};
```

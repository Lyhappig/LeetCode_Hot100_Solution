## 字符串解码

### 问题

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k` ，例如不会出现像 `3a` 或 `2[4]` 的输入。

提示：

- `1 <= s.length <= 30`
- `s` 由小写英文字母、数字和方括号 `'[]'` 组成
- `s` 保证是一个 **有效** 的输入。
- `s` 中所有整数的取值范围为 `[1, 300]` 

### 思路一（栈）

括号内嵌套括号，而且需要从内向外拼接字符串，这类似于判断括号表达式，需要使用栈。

设置两个辅助栈 $st_1,st_2$，前者保存编码重复的次数 $k$，后者保存 `encoded_string`，从左到右遍历字符串的每个字符 $s[i]$，判断：

- 若 $s[i]$ 是数字字符，则取出该数字子串入栈 $st_1$；
- 若 $s[i]$ 是英文字母或左括号，直接入栈 $st_2$；
- 若 $s[i]$ 是右括号，首先从 $st_1$ 的栈顶弹出重复次数 $k$，接着从 $st_2$ 中不断弹出字母字符串并拼接，直到弹出左括号，这代表了一次编码。将拼接后的结果重复 $k$ 次作为字母字符串入栈。

最终 $st_1$ 为空，$st_2$ 的栈顶即为答案。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```C++
class Solution {
public:
    string decodeString(string s) {
        vector<int> st1;
        vector<string> st2;
        for(int i = 0; i < s.size(); i++) {
            if (isdigit(s[i])) {
                int num = 0;
                int j = i;
                while (isdigit(s[j])) {
                    num = num * 10 + s[j] - '0';
                    j++;
                }
                st1.push_back(num);
                i = j - 1;
            } else if (s[i] == ']') {
                int cnt = st1.back();
                st1.pop_back();
                string res;
                int j = st2.size() - 1;
                while (j >= 0 && st2[j] != "[") j--;
                for (int k = j + 1; k < st2.size(); k++) res += st2[k];
                while (!st2.empty() && st2.back() != "[") st2.pop_back();
                if (!st2.empty() && st2.back() == "[") st2.pop_back();
                string temp;
                for (int i = 0; i < cnt; i++) {
                    temp += res;
                }
                st2.push_back(temp);
            } else {
                string now;
                now += s[i];
                st2.push_back(now);
            }
        }
        string ans;
        for (int i = 0; i < st2.size(); i++) {
            ans += st2[i];
        }
        return ans;
    }
};
```

### 思路二（递归）

总体思路与方法一相同，不同点在于以左括号和右括号分别作为递归开始与终止条件：

- 当下标为 $i$ 的字符是数字字符时，不断更新其数值 $k$；
- 当下标为 $i$ 的字符是右括号时，返回当前括号内记录的解码字符串与右括号的索引（更新上层递归后指针位置）；
- 当下标为 $i$ 的字符是左括号时，开启新一层递归，记录编码字符串 `encoded_string` 和递归后的最新索引 $i$，并重复编码字符串 $k$。

#### 时空复杂度

时间复杂度 $O(n)$

空间复杂度 $O(n)$​

#### 代码

```python
class Solution:
    def decodeString(self, s: str) -> str:
        def dfs(i, s):
            x = 0
            ret = ""
            while i < len(s):
                if '0' <= s[i] <= '9':
                    x = x * 10 + int(s[i])
                elif s[i] == '[':
                    i, tmp = dfs(i + 1, s)
                    ret += x * tmp
                    x = 0
                elif s[i] == ']':
                    return i, ret
                else:
                    ret += s[i]
                i += 1
            return ret
        return dfs(0, s)
```
